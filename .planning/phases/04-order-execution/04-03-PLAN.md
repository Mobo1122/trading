    **Method: `async def record_fill(self, order_id: str, trade: Trade, fill: Fill) -> None`**
    Flow:
    1. Extract from fill.execution: execId, side, shares, price, avgPrice, cumQty, exchange, lastLiquidity, permId, time
    2. Look up expected_price from DB Order record (order.expected_price)
    3. Calculate slippage if expected_price is available:
       - Map side: "BOT" -> "BUY", "SLD" -> "SELL"
       - Call calculate_slippage(action, expected_price, fill.execution.price, fill.execution.shares)
       - Returns (slippage_dollars, slippage_bps)
    4. Create ExecutionRecord (ORM) in DB:
       - order_id=order_id
       - exec_id=fill.execution.execId
       - side=fill.execution.side
       - quantity=fill.execution.shares
       - price=fill.execution.price
       - avg_price=fill.execution.avgPrice
       - cum_qty=fill.execution.cumQty
       - exchange=fill.execution.exchange
       - liquidity=fill.execution.lastLiquidity
       - timestamp=fill.time (use datetime.now(timezone.utc) if fill.time is epoch/None)
       - expected_price=expected_price (from DB Order)
       - slippage=slippage_dollars
       - slippage_bps=slippage_bps
    5. Update Order record: fill_price=fill.execution.avgPrice, filled_quantity=fill.execution.cumQty
    6. Update ib_perm_id if not yet set: order.ib_perm_id = fill.execution.permId
    7. Log with structlog: order_id, exec_id, price, quantity, slippage

    **Handle duplicate exec_id gracefully:** Wrap the insert in try/except for IntegrityError (unique constraint on exec_id). If duplicate, log warning and skip.

    **Method: `async def record_commission(self, order_id: str, trade: Trade, fill: Fill, report: CommissionReport) -> None`**
    Flow:
    1. Find the ExecutionRecord by exec_id=report.execId (or fill.execution.execId)
    2. Update: commission=report.commission, realized_pnl=report.realizedPNL
    3. Accumulate on Order: total_commission += report.commission
    4. Log with structlog

    **Handle commission arriving before fill:** If ExecutionRecord not found by exec_id, log warning and store commission data as a pending update. On next record_fill for that exec_id, apply pending commission. Use a simple dict `_pending_commissions: dict[str, CommissionReport]` as buffer.

    **Method: `async def get_slippage_report(self, order_id: str) -> SlippageReport | None`**
    - Query Order and its ExecutionRecords from DB
    - If no expected_price or no fills: return None
    - Build SlippageReport from Order data (action, expected_price, fill_price, filled_quantity, computed slippage)

    **Key notes:**
    - Use `from trading.db.models import ExecutionRecord as ExecutionRecordORM, Order` (avoid name collision with Pydantic model)
    - Use `from trading.orders.models import calculate_slippage, SlippageReport`
    - Use `from trading.db.session import get_session`
    - All DB operations use `async with get_session(self._session_factory) as session:`
    - Import EPOCH from datetime to check fill.time validity: `EPOCH = datetime(1970, 1, 1, tzinfo=timezone.utc)`
    - Use `trigger=` not `event=` in structlog calls

  <files>src/trading/orders/recovery.py</files>
  <action>
    Create `src/trading/orders/recovery.py` with class `OrderRecoveryManager`.

    **Constructor:**
    - ib: IB instance
    - order_tracker: OrderTracker
    - execution_service: OrderExecutionService (for re-subscribing Trade events)
    - session_factory: async_sessionmaker
    - Use structlog.get_logger(component="order_recovery")

    **Method: `async def recover_after_reconnect(self) -> dict`**
    Returns a summary dict: {recovered: int, filled: int, cancelled: int, orphaned: int}

    Flow:
    1. Call `trades = await self._ib.reqOpenOrdersAsync()` to get current IB open orders
    2. Query DB for in-flight orders (current_state NOT IN terminal states):
       ```python
       terminal_states = [OrderState.FILLED.value, OrderState.CANCELLED.value, OrderState.ERROR.value]
       result = await session.execute(
           select(Order).where(Order.current_state.not_in(terminal_states))
       )
       db_orders = result.scalars().all()
       ```
    3. Build IB permId lookup: `ib_perm_map = {t.order.permId: t for t in trades if t.order.permId}`
    4. For each db_order:
       a. If db_order.ib_perm_id in ib_perm_map:
          - Order still open in IB -- re-subscribe to Trade events
          - Call `self._execution_service.resubscribe_trade(db_order.id, ib_trade)` (add this method)
          - Increment recovered count
       b. Else (not in open orders):
          - Check IB fills: `fills = [f for f in self._ib.fills() if f.execution.permId == db_order.ib_perm_id]`
          - If fills exist: transition to FILLED via `handle_ib_status(db_order.id, "Filled")`
          - If no fills and no open order: transition to CANCELLED via `handle_ib_status(db_order.id, "Cancelled")`
          - Handle TransitionNotAllowed gracefully (order might already be in correct state)
    5. Log recovery summary
    6. Return summary dict

    **Also add to OrderExecutionService (modify execution_service.py):**
    Add method `resubscribe_trade(self, order_id: str, trade: Trade) -> None`:
    - Subscribe to trade.statusEvent, trade.fillEvent, trade.commissionReportEvent (same as submit_order)
    - Store in self._active_trades[order_id] = trade
    - Log resubscription

    **Key notes:**
    - Import OrderState from trading.db.models for terminal state check
    - Import Order from trading.db.models
    - Wrap handle_ib_status calls in try/except TransitionNotAllowed -- order might already be in correct final state
    - Use statemachine.exceptions.TransitionNotAllowed
    - If db_order has no ib_perm_id (order was created but never got IB acknowledgment): mark as ERROR
    - Log each recovery action with order_id and recovery_action for audit trail
    - Use `trigger=` not `event=` in structlog calls
  </action>
