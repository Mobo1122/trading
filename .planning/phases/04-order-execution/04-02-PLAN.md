  <files>src/trading/orders/execution_service.py</files>
  <action>
    Create `src/trading/orders/execution_service.py` with class `OrderExecutionService`.

    **Constructor dependencies:**
    - ib: IB instance (from ib_async)
    - risk_manager: RiskManager instance
    - order_tracker: OrderTracker instance
    - session_factory: async_sessionmaker for DB access
    - fill_tracker: optional FillTracker (set later via property, None initially -- Plan 03 creates it)

    **Primary method: `async def submit_order(self, proposal: TradeProposal, timeout: float = 10.0) -> tuple[RiskDecision, Trade | None]`**

    Flow:
    1. Call `evaluate_with_failsafe(self._risk_manager, proposal, timeout=timeout)` -- ALWAYS FIRST
    2. If decision.approved is False: log rejection, return (decision, None)
    3. Determine if single-leg or multi-leg:
       - Single-leg (len(proposal.legs) == 1): construct contract + order from leg
       - Multi-leg (len(proposal.legs) > 1): use ComboOrderBuilder.build_from_trade_legs()
    4. Create DB Order record via `_create_db_order(proposal, contract, ib_order)`:
       - async with get_session: create Order with symbol, sec_type, action, quantity, order_type,
         limit_price, stop_price, expected_price (from proposal first leg's order lmtPrice or None),
         proposal_id=proposal.proposal_id
       - For combos: set combo_legs to JSON string of leg details
       - Return the order_id (str)
    5. Create state machine: `self._order_tracker.create_order(order_id)`
    6. Place order: `trade = self._ib.placeOrder(contract, ib_order)`
    7. Update DB with ib_order_id: `trade.order.orderId`
    8. Subscribe to Trade events for state machine bridging:
       - `trade.statusEvent += lambda t: asyncio.ensure_future(self._on_status(order_id, t))`
       - `trade.fillEvent += lambda t, f: asyncio.ensure_future(self._on_fill(order_id, t, f))`
       - `trade.commissionReportEvent += lambda t, f, r: asyncio.ensure_future(self._on_commission(order_id, t, f, r))`
    9. Transition state machine: `await self._order_tracker.transition(order_id, "submit")`
    10. Store mapping: `self._active_trades[order_id] = trade`
    11. Return (decision, trade)

    **Single-leg contract construction: `_build_single_leg(leg: TradeLeg) -> tuple[Contract, Order]`**
    - If leg.contract is not None: use it directly (already qualified)
    - Else: create Option(symbol, expiry, strike, right, "SMART", currency="USD")
      and raise ValueError("Leg contract must be pre-qualified")
    - For order type, inspect leg.order:
      - If leg.order is not None: use it directly
      - Else: raise ValueError("Leg must have an order object set")
    - Return (contract, order)

    **Multi-leg construction: `_build_multi_leg(proposal: TradeProposal) -> tuple[Bag, Order]`**
    - Use ComboOrderBuilder.build_from_trade_legs(symbol, proposal.legs)
    - For the order: use first leg's order object (the combo order), raise if None
    - Call ComboOrderBuilder.apply_combo_routing(order) for NonGuaranteed flag
    - Return (bag, order)

    **Event handlers (private async methods):**
    - `_on_status(order_id, trade)`: call `self._order_tracker.handle_ib_status(order_id, trade.orderStatus.status)`
      Log with structlog. Also update ib_perm_id in DB on first status callback (trade.order.permId).
    - `_on_fill(order_id, trade, fill)`: if self._fill_tracker is not None, delegate to fill_tracker.
      Also update Order.fill_price and Order.filled_quantity in DB.
    - `_on_commission(order_id, trade, fill, report)`: if self._fill_tracker is not None, delegate.
      Also accumulate Order.total_commission in DB.

    **Cancel method: `async def cancel_order(self, order_id: str) -> Trade | None`**
    - Look up trade from self._active_trades[order_id]
    - Transition state machine: `await self._order_tracker.transition(order_id, "request_cancel")`
    - Call `self._ib.cancelOrder(trade.order)`
    - Return trade (statusEvent will fire "Cancelled" or "ApiCancelled")

    **Helper: `_update_order_field(order_id, **kwargs)` -- convenience for DB updates**
    - async with get_session: select Order, update fields from kwargs

    **Key implementation notes:**
    - Use `structlog.get_logger(component="execution_service")` for logging
    - Use `trigger=` not `event=` in structlog calls (01-05 decision)
    - Use `asyncio.ensure_future()` for event callbacks since ib_async events are sync
    - Store `_active_trades: dict[str, Trade]` for lookup during cancel/recovery
    - The fill_tracker property allows Plan 03 to set it after construction:
      ```python
      @property
      def fill_tracker(self):
          return self._fill_tracker

      @fill_tracker.setter
      def fill_tracker(self, tracker):
          self._fill_tracker = tracker
      ```
