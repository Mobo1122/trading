<objective>
Integrate the Finnhub earnings calendar API to fetch upcoming earnings dates, store them in the database, and expose earnings flags for underlyings approaching earnings events. This enables downstream agents to adjust options strategies around IV expansion/crush events.

Purpose: Options premiums expand before earnings (IV expansion) and collapse after (IV crush). Knowing when earnings occur is critical for strategy selection -- selling premium before earnings vs. buying after earnings. The scanner agent (Phase 5) will use earnings flags to filter and prioritize opportunities.
Output: EarningsCalendar service with fetch, store, and flag functionality.
</objective>

    Constructor takes: `session_factory: async_sessionmaker`, `settings: Settings`.

    Internal state:
    - `_cache: dict[str, list[EarningsFlag]]` -- symbol -> cached earnings flags
    - `_last_refresh: float | None` -- timestamp of last full refresh
    - `_log: structlog.BoundLogger` bound with `component="earnings_calendar"`

    Methods:

    `async def fetch_earnings(self, symbol: str, from_date: date, to_date: date) -> list[dict]`:
    - Get API key from `self.settings.market_data.finnhub_api_key`
    - If API key is empty/missing: log warning `earnings.no_api_key` and return empty list
    - Try using finnhub SDK first:
      ```python
      import finnhub
      client = finnhub.Client(api_key=api_key)
      result = client.earnings_calendar(
          _from=from_date.isoformat(),
          to=to_date.isoformat(),
          symbol=symbol,
      )
      ```
    - If finnhub SDK not available (ImportError), use httpx fallback:
      ```python
      import httpx
      async with httpx.AsyncClient() as http:
          resp = await http.get(
              "https://finnhub.io/api/v1/calendar/earnings",
              params={"from": from_date.isoformat(), "to": to_date.isoformat(), "symbol": symbol, "token": api_key},
              timeout=10.0,
          )
          resp.raise_for_status()
          result = resp.json()
      ```
    - Note: The finnhub SDK is synchronous. If using the SDK, wrap the call in `asyncio.get_event_loop().run_in_executor(None, lambda: client.earnings_calendar(...))` to avoid blocking the event loop.
    - Parse response: `result.get("earningsCalendar", [])` -- each entry has: date, epsEstimate, hour (bmo/amc/dmh), symbol, revenueEstimate
    - Return list of raw dicts
    - On any error (HTTP, parsing, timeout): log warning `earnings.fetch_failed` with symbol and error, return empty list

    `async def store_earnings(self, earnings_data: list[dict]) -> int`:
    - Open async session
    - For each entry in earnings_data:
      - Parse `earnings_date = date.fromisoformat(entry["date"])`
      - `hour = entry.get("hour")` -- bmo, amc, dmh, or None
      - `eps_estimate = entry.get("epsEstimate")` -- may be None
      - `revenue_estimate = entry.get("revenueEstimate")` -- may be None
      - `symbol = entry["symbol"]`
      - Use upsert (on conflict do update -- we want to update eps_estimate if it changes):
        ```python
        from sqlalchemy.dialects.postgresql import insert as pg_insert
        stmt = pg_insert(EarningsEvent).values(
            symbol=symbol, earnings_date=earnings_date, hour=hour,
            eps_estimate=eps_estimate, revenue_estimate=revenue_estimate,
        ).on_conflict_do_update(
            index_elements=["symbol", "earnings_date"],
            set_={"hour": hour, "eps_estimate": eps_estimate, "revenue_estimate": revenue_estimate, "fetched_at": func.now()},
        )
        await session.execute(stmt)
        ```
    - Commit
    - Log: `earnings.stored` with count
    - Return count

    `async def refresh_watchlist(self, symbols: list[str]) -> dict[str, int]`:
    - Calculate date range: today to today + `settings.market_data.earnings_lookout_days * 4` (look further ahead than the flag window to pre-populate)
    - For each symbol:
      - `data = await self.fetch_earnings(symbol, from_date, to_date)`
      - `count = await self.store_earnings(data)`
      - results[symbol] = count
    - Update `_last_refresh = time.time()`
    - Clear `_cache` (force re-computation of flags)
    - Log: `earnings.watchlist_refreshed` with total symbols, total events found
    - Return results

    `async def get_earnings_flags(self, symbols: list[str]) -> list[EarningsFlag]`:
    - Check cache for all symbols. If all cached and cache age < 24 hours, return cached values.
    - Query database: SELECT from earnings_events WHERE symbol IN (symbols) AND earnings_date >= today AND earnings_date <= today + lookout_days ORDER BY earnings_date ASC
    - For each result row:
      - Calculate `days_until = (row.earnings_date - date.today()).days`
      - Create `EarningsFlag(symbol=row.symbol, earnings_date=row.earnings_date, days_until=days_until, hour=row.hour, eps_estimate=row.eps_estimate, revenue_estimate=row.revenue_estimate, fetched_at=row.fetched_at)`
    - Cache results per symbol
    - Return list of EarningsFlags

    `async def get_earnings_flag(self, symbol: str) -> EarningsFlag | None`:
    - Convenience method for single symbol
    - Call `flags = await self.get_earnings_flags([symbol])`
    - Return first flag for the symbol, or None if no upcoming earnings

    `def needs_refresh(self) -> bool`:
    - Return True if `_last_refresh is None` or `time.time() - _last_refresh > 86400` (24 hours)
    - Used by the app lifecycle to trigger daily refresh
