<objective>
Build the IV rank/percentile analytics engine: fetch historical implied volatility data from IB, store it in TimescaleDB, and compute IV rank and IV percentile metrics for any underlying. Includes rate-limited IB historical data bootstrapping and periodic refresh.

Purpose: IV rank/percentile is a critical input for options strategy selection. High IV rank suggests selling strategies (premium is expensive), low IV rank suggests buying strategies. The scanner agent (Phase 5) will use this data to filter opportunities.
Output: IVHistoryManager for data fetching/storage, IVEngine for computation with caching.
</objective>

    **Create `src/trading/analytics/iv_history.py`** with `IVHistoryManager`:

    Constructor takes: `ib: IB`, `session_factory: async_sessionmaker`, `settings: Settings`.

    Internal state:
    - `_request_timestamps: list[float]` -- tracks timestamps of recent IB historical data requests for pacing
    - `_log: structlog.BoundLogger` bound with `component="iv_history"`

    Rate limiting constants:
    - `MAX_REQUESTS_PER_WINDOW = 55` (conservative; IB allows 60 per 10 minutes, leave margin)
    - `WINDOW_SECONDS = 600` (10 minutes)
    - `MIN_REQUEST_SPACING = 2.5` (seconds between requests; IB requires 2s minimum, add margin)

    Methods:

    `async def _wait_for_rate_limit(self) -> None`:
    - Clean expired timestamps: remove entries older than WINDOW_SECONDS from `_request_timestamps`
    - If len >= MAX_REQUESTS_PER_WINDOW: calculate wait time until oldest timestamp expires, `await asyncio.sleep(wait_time)`
    - If last request was less than MIN_REQUEST_SPACING seconds ago: `await asyncio.sleep(MIN_REQUEST_SPACING - elapsed)`
    - Append current time to `_request_timestamps`
    - Log: `iv_history.rate_limit` with requests_in_window, wait_time (only if waited)

    `async def fetch_iv_history(self, symbol: str, duration: str = "1 Y") -> list[tuple[date, float, float, float]]`:
    - CRITICAL: Use STK contract, NOT OPT contract. `contract = Stock(symbol, "SMART", "USD")`
    - Call `await self.ib.qualifyContractsAsync(contract)`
    - Await rate limiter: `await self._wait_for_rate_limit()`
    - Call:
      ```python
      bars = await self.ib.reqHistoricalDataAsync(
          contract=contract,
          endDateTime="",
          durationStr=duration,
          barSizeSetting="1 day",
          whatToShow="OPTION_IMPLIED_VOLATILITY",
          useRTH=True,
          formatDate=1,
      )
      ```
    - If bars is None or empty:
      - Log warning: `iv_history.no_data` with symbol
      - Return empty list
    - Convert bars to list of tuples: `(bar.date, bar.close, bar.high, bar.low)` where `bar.close` is the daily closing IV, `bar.high` is daily IV high, `bar.low` is daily IV low
    - Handle the case where `bar.date` might be a string or a date object (ib_async can return either depending on formatDate)
    - Return the list
    - On any IB error (exception): log warning `iv_history.fetch_failed`, return empty list (graceful degradation)

    `async def store_iv_history(self, symbol: str, iv_data: list[tuple[date, float, float, float]]) -> int`:
    - Open async session
    - For each (date, iv_close, iv_high, iv_low) in iv_data:
      - Create `IVHistory` ORM instance with timestamp=date, symbol=symbol, iv_close=iv_close, iv_high=iv_high, iv_low=iv_low
    - Use `session.merge()` or INSERT ON CONFLICT DO NOTHING to handle duplicates (same symbol+date)
    - Actually, since we have a unique constraint on (symbol, DATE(timestamp)), use a try/except around each insert, or batch with `INSERT ... ON CONFLICT DO NOTHING` via raw SQL for efficiency
    - Better approach: Use SQLAlchemy `insert().on_conflict_do_nothing()` with the `postgresql` dialect:
      ```python
      from sqlalchemy.dialects.postgresql import insert as pg_insert
      stmt = pg_insert(IVHistory).values(records).on_conflict_do_nothing()
      await session.execute(stmt)
      ```
    - Commit and return count of records stored
    - Log: `iv_history.stored` with symbol, count

    `async def bootstrap_symbol(self, symbol: str) -> int`:
    - Fetch 1 year of IV history: `iv_data = await self.fetch_iv_history(symbol, "1 Y")`
    - Store: `count = await self.store_iv_history(symbol, iv_data)`
    - Log: `iv_history.bootstrapped` with symbol, data_points=count
    - Return count

    `async def bootstrap_watchlist(self, symbols: list[str]) -> dict[str, int]`:
    - For each symbol in symbols (sequentially, to respect rate limits):
      - `count = await self.bootstrap_symbol(symbol)`
      - results[symbol] = count
    - Log: `iv_history.watchlist_bootstrapped` with total symbols, total data points
    - Return results dict
    - IMPORTANT: Do NOT use asyncio.gather here. Historical data requests must be paced sequentially due to IB rate limits.

    `async def get_stored_history(self, symbol: str, days: int = 252) -> list[float]`:
    - Query iv_history table for the given symbol, last N days, ordered by timestamp ASC
    - Return list of iv_close values
    - Use SQLAlchemy: `select(IVHistory.iv_close).where(IVHistory.symbol == symbol, IVHistory.timestamp >= cutoff).order_by(IVHistory.timestamp.asc())`
    - Return empty list if no data

    `async def snapshot_current_iv(self, symbol: str, current_iv: float, hv: float | None = None) -> None`:
    - Store today's IV reading (called daily at market close or on-demand)
    - Create IVHistory record with today's date, symbol, iv_close=current_iv, hv_close=hv
    - Use on_conflict_do_nothing for idempotency
    - Log: `iv_history.snapshot_stored`

    Import: `from ib_async import IB, Stock`, `from trading.db.models import IVHistory`, `from sqlalchemy import select`, `from sqlalchemy.dialects.postgresql import insert as pg_insert`, `from datetime import date, datetime, timedelta`, `import asyncio`, `import structlog`, `import time`.

    **Create `src/trading/analytics/iv_engine.py`** with `IVEngine`:

    Constructor takes: `iv_history: IVHistoryManager`, `settings: Settings`.

    Internal state:
    - `_cache: dict[str, IVData]` -- symbol -> cached IVData
    - `_cache_timestamps: dict[str, float]` -- symbol -> time.time() of last computation
    - `_refresh_interval: float` -- from `settings.market_data.iv_refresh_interval_minutes * 60` (convert to seconds)
    - `_log: structlog.BoundLogger` bound with `component="iv_engine"`

    Static methods (pure computation, no side effects):

    `@staticmethod`
    `def calculate_iv_rank(current_iv: float, iv_history: list[float]) -> float | None`:
    - If `not iv_history` or `len(iv_history) < 20`: return None (insufficient data -- need at least ~1 month)
    - `low = min(iv_history)`
    - `high = max(iv_history)`
    - If `high == low`: return 50.0 (no range)
    - Return `((current_iv - low) / (high - low)) * 100.0`
    - Clamp result to 0-100 range: `max(0.0, min(100.0, result))`

    `@staticmethod`
    `def calculate_iv_percentile(current_iv: float, iv_history: list[float]) -> float | None`:
    - If `not iv_history` or `len(iv_history) < 20`: return None (insufficient data)
    - `below = sum(1 for iv in iv_history if iv < current_iv)`
    - Return `(below / len(iv_history)) * 100.0`

    Instance methods:

    `async def compute(self, symbol: str, current_iv: float | None = None, hv: float | None = None) -> IVData`:
    - Check cache: if symbol in `_cache` and cache age < `_refresh_interval`, return cached value
    - Fetch stored history: `history = await self.iv_history.get_stored_history(symbol, days=252)`
    - If `current_iv is None`:
      - Use the most recent value from history if available: `current_iv = history[-1] if history else None`
    - Compute IV rank and percentile (only if current_iv is not None):
      - `iv_rank = self.calculate_iv_rank(current_iv, history)` if current_iv else None
      - `iv_percentile = self.calculate_iv_percentile(current_iv, history)` if current_iv else None
    - Compute high/low from history:
      - `iv_high = max(history) if history else None`
      - `iv_low = min(history) if history else None`
    - Create `IVData`:
      ```python
      iv_data = IVData(
          symbol=symbol,
          current_iv=current_iv,
          iv_rank=iv_rank,
          iv_percentile=iv_percentile,
          iv_high_52w=iv_high,
          iv_low_52w=iv_low,
          hv_current=hv,
          data_points=len(history),
          computed_at=datetime.utcnow(),
      )
      ```
    - Store in cache: `self._cache[symbol] = iv_data`, `self._cache_timestamps[symbol] = time.time()`
    - Log: `iv_engine.computed` with symbol, iv_rank, iv_percentile, data_points
    - Return iv_data

    `async def compute_batch(self, symbols: list[str], current_ivs: dict[str, float] | None = None) -> dict[str, IVData]`:
    - For each symbol: `result[symbol] = await self.compute(symbol, current_iv=current_ivs.get(symbol) if current_ivs else None)`
    - Note: Sequential, not parallel, because each compute may trigger DB reads. Use asyncio.gather if DB handles concurrent reads well.
    - Actually, DB reads CAN be concurrent. Use `asyncio.gather(*[self.compute(s, ...) for s in symbols])`
    - Return dict

    `def invalidate_cache(self, symbol: str | None = None) -> None`:
    - If symbol is None: clear all caches
    - Else: remove symbol from `_cache` and `_cache_timestamps`

    `def get_cached(self, symbol: str) -> IVData | None`:
    - Return `_cache.get(symbol)` (may be stale, caller's responsibility to check `computed_at`)
