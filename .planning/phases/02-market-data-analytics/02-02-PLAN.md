<objective>
Build the complete real-time market data streaming pipeline: subscription management with IB's 100-line limit, Redis pub/sub distribution with latest-value caching, buffered TimescaleDB persistence, and staleness detection. This is the core data flow that converts IB tick events into distributed, persisted market data.

Purpose: This pipeline is the primary data source for the risk engine (Phase 3) and agent pipeline (Phase 5). Without it, no downstream component has access to live market data.
Output: Five interconnected modules that together stream quotes and Greeks from IB to Redis and TimescaleDB.
</objective>

    **Create `src/trading/market_data/subscriber.py`** with `SubscriptionManager`:

    Constructor takes: `ib: IB`, `settings: Settings` (reads `max_subscription_lines`, `reserved_lines` from `settings.market_data`).

    Internal state:
    - `_active: dict[int, SubscriptionInfo]` (conId -> SubscriptionInfo from models.py)
    - `_priority_pins: set[int]` (conIds that cannot be evicted -- HIGH priority)
    - `_underlying_map: dict[str, int]` (symbol -> conId, tracks which underlyings are subscribed)
    - `_log: structlog.BoundLogger` bound with `component="subscription_manager"`

    Properties:
    - `available_lines -> int`: `max_subscription_lines - len(self._active)`
    - `active_count -> int`: `len(self._active)`
    - `active_subscriptions -> dict[int, SubscriptionInfo]`: returns copy of `_active`

    Methods:

    `async def subscribe_underlying(self, symbol: str, priority: SubscriptionPriority = SubscriptionPriority.MEDIUM) -> Ticker | None`:
    - Check if symbol already subscribed via `_underlying_map`; if so, return existing ticker
    - If no available lines, call `_evict_one()`; if eviction fails, log warning and return None
    - Create `Stock(symbol, "SMART", "USD")` contract
    - Call `await self.ib.qualifyContractsAsync(contract)` to resolve conId
    - Call `self.ib.reqMktData(contract, genericTickList="100,101,104,106,165")` -- includes OI, volume, histVol, impliedVol, 52-week
    - Create `SubscriptionInfo` with current datetime, store in `_active[contract.conId]`
    - Store in `_underlying_map[symbol] = contract.conId`
    - If priority is HIGH, add to `_priority_pins`
    - Log: `subscription.underlying_added` with symbol, conId, active_count, available_lines
    - Return the Ticker

    `async def subscribe_option(self, contract: Option, priority: SubscriptionPriority = SubscriptionPriority.LOW) -> Ticker | None`:
    - CRITICAL: Check if underlying is subscribed via `_underlying_map`. If NOT, auto-subscribe the underlying first with MEDIUM priority. Log this auto-subscription. This is required because IB won't populate Greeks without an active underlying subscription.
    - Check if option conId already in `_active`; if so, return existing ticker
    - If no available lines, call `_evict_one()`; if fails, return None
    - Call `await self.ib.qualifyContractsAsync(contract)` if contract.conId is 0
    - Call `self.ib.reqMktData(contract, genericTickList="100,101")` -- OI and volume; Greeks come automatically
    - Store in `_active`
    - If priority is HIGH, add to `_priority_pins`
    - Log: `subscription.option_added` with symbol, conId, active_count
    - Return the Ticker

    `async def unsubscribe(self, con_id: int) -> bool`:
    - If not in `_active`, return False
    - Call `self.ib.cancelMktData(info.contract)` (need to store contract in SubscriptionInfo -- add `contract` field to SubscriptionInfo model or store it separately)
    - Remove from `_active`, `_priority_pins`, `_underlying_map` as appropriate
    - Log: `subscription.removed` with conId
    - Return True

    Note: SubscriptionInfo from models.py is a Pydantic model and might not hold the ib_async Contract object well. Instead, maintain a separate `_contracts: dict[int, Contract]` dict mapping conId -> Contract alongside `_active`. Keep SubscriptionInfo for metadata only.

    `def _evict_one(self) -> bool`:
    - Filter `_active` for conIds NOT in `_priority_pins`
    - Sort by `subscribed_at` ascending (oldest first) -- LRU eviction
    - If no evictable candidates, return False
    - Cancel market data for the oldest: `self.ib.cancelMktData(contract)`
    - Remove from `_active`, `_contracts`, `_underlying_map`
    - Log: `subscription.evicted` with evicted conId, symbol
    - Return True

    `def pin(self, con_id: int) -> None`: Add to `_priority_pins` (for open positions).

    `def unpin(self, con_id: int) -> None`: Remove from `_priority_pins`.

    `def update_last_seen(self, con_id: int) -> None`: Update `_active[con_id].last_update = datetime.utcnow()` if exists. Used by staleness monitor.

    **Create `src/trading/market_data/distributor.py`** with `RedisDistributor`:

    Constructor takes: `redis_client: Redis` (the async Redis client from Phase 1). Bind structlog logger with `component="redis_distributor"`.

    Channel naming constants (class-level):
    - `QUOTE_CHANNEL = "mktdata:quote:{symbol}"`
    - `GREEKS_CHANNEL = "mktdata:greeks:{symbol}:{con_id}"`
    - `STALENESS_CHANNEL = "mktdata:stale"`
    - `QUOTE_HASH = "mktdata:latest:quote:{symbol}"`
    - `GREEKS_HASH = "mktdata:latest:greeks:{con_id}"`

    Methods:

    `async def publish_quote(self, snapshot: QuoteSnapshot) -> None`:
    - Serialize snapshot to JSON via `snapshot.model_dump_json()`
    - Publish to channel: `await self.redis.publish(QUOTE_CHANNEL.format(symbol=snapshot.symbol), payload)`
    - Update HSET cache: `await self.redis.hset(QUOTE_HASH.format(symbol=snapshot.symbol), mapping=snapshot.model_dump(mode="json"))` -- note: hset mapping values must be strings, so use `model_dump(mode="json")` and convert non-string values. Actually, use a dict comprehension: `{k: json.dumps(v) if not isinstance(v, str) else v for k, v in snapshot.model_dump(mode="json").items()}`
    - Wrap ALL Redis operations in try/except. On failure, log warning `redis.publish_quote_failed` but DO NOT raise (cache errors are non-fatal -- Phase 1 decision).

    `async def publish_greeks(self, snapshot: GreeksSnapshot) -> None`:
    - Same pattern as publish_quote but uses GREEKS_CHANNEL and GREEKS_HASH
    - Channel: `GREEKS_CHANNEL.format(symbol=snapshot.symbol, con_id=snapshot.con_id)`
    - Hash: `GREEKS_HASH.format(con_id=snapshot.con_id)`
    - Non-fatal error handling

    `async def publish_stale(self, con_id: int, symbol: str, seconds_since_update: float) -> None`:
    - Publish JSON to STALENESS_CHANNEL: `{"con_id": con_id, "symbol": symbol, "seconds_since_update": seconds_since_update, "timestamp": datetime.utcnow().isoformat()}`
    - Non-fatal error handling

    `async def get_latest_quote(self, symbol: str) -> dict | None`:
    - `data = await self.redis.hgetall(QUOTE_HASH.format(symbol=symbol))`
    - Return data if non-empty, None otherwise
    - Non-fatal error handling (return None on error)

    `async def get_latest_greeks(self, con_id: int) -> dict | None`:
    - Same pattern with GREEKS_HASH
    - Non-fatal error handling

    Use `import json` and `from math import isnan` at module level. Import `QuoteSnapshot, GreeksSnapshot` from `trading.market_data.models`.

    **Create `src/trading/market_data/writer.py`** with `TimescaleDBWriter`:

    Constructor takes: `session_factory: async_sessionmaker`, `settings: Settings` (reads `batch_flush_interval_seconds`, `batch_size` from `settings.market_data`).

    Internal state:
    - `_quote_buffer: list[MarketQuote]` (SQLAlchemy model instances)
    - `_greeks_buffer: list[OptionGreeks]` (SQLAlchemy model instances)
    - `_flush_task: asyncio.Task | None`
    - `_running: bool = False`
    - `_log: structlog.BoundLogger` bound with `component="tsdb_writer"`

    Methods:

    `async def start(self) -> None`:
    - Set `_running = True`
    - Start the flush loop: `self._flush_task = asyncio.create_task(self._flush_loop())`
    - Log: `writer.started`

    `async def stop(self) -> None`:
    - Set `_running = False`
    - Cancel flush task if running
    - Do one final flush to persist any remaining buffered data
    - Log: `writer.stopped` with counts of remaining records flushed

    `def buffer_quote(self, snapshot: QuoteSnapshot) -> None`:
    - Create a `MarketQuote` ORM instance from the snapshot fields
    - Append to `_quote_buffer`
    - No async, no I/O -- just buffer in memory

    `def buffer_greeks(self, snapshot: GreeksSnapshot) -> None`:
    - Create an `OptionGreeks` ORM instance from the snapshot fields
    - Append to `_greeks_buffer`

    `async def _flush_loop(self) -> None`:
    - While `_running`: `await asyncio.sleep(flush_interval)`, then `await self._flush()`
    - Wrap the loop body in try/except to prevent task death on transient DB errors

    `async def _flush(self) -> None`:
    - If both buffers empty, return immediately
    - Swap buffers atomically: `quotes, self._quote_buffer = self._quote_buffer[:batch_size], self._quote_buffer[batch_size:]` (same for greeks)
    - Open async session: `async with self._session_factory() as session:`
    - `session.add_all(quotes + greeks)`
    - `await session.commit()`
    - Log: `writer.flushed` with quote_count, greeks_count
    - On exception: log `writer.flush_failed` with error, do NOT re-raise (non-fatal, data will be retried or lost -- acceptable for tick data)

    Import `MarketQuote, OptionGreeks` from `trading.db.models`.
    Import `QuoteSnapshot, GreeksSnapshot` from `trading.market_data.models`.

    **Create `src/trading/market_data/staleness.py`** with `StalenessMonitor`:

    Constructor takes: `subscriber: SubscriptionManager`, `distributor: RedisDistributor`, `settings: Settings`.

    Internal state:
    - `_check_task: asyncio.Task | None`
    - `_running: bool = False`
    - `_log: structlog.BoundLogger`

    Methods:

    `async def start(self) -> None`:
    - Start periodic check task: `asyncio.create_task(self._check_loop())`

    `async def stop(self) -> None`:
    - Set `_running = False`, cancel task

    `async def _check_loop(self) -> None`:
    - While `_running`: sleep 10 seconds, then `await self._check_all()`

    `async def _check_all(self) -> None`:
    - Get current time
    - Iterate `subscriber.active_subscriptions`
    - For each subscription where `last_update` is not None:
      - If `(now - last_update).total_seconds() > settings.market_data.staleness_threshold_seconds`:
        - `await distributor.publish_stale(con_id, symbol, seconds_since_update)`
        - Log: `staleness.detected` with con_id, symbol, seconds
    - For subscriptions where `last_update is None` and `subscribed_at` was more than threshold ago:
      - Also flag as stale (never received any data)

    Constructor takes: `ib: IB`, `subscriber: SubscriptionManager`, `distributor: RedisDistributor`, `writer: TimescaleDBWriter`, `settings: Settings`.

    Methods:

    `async def subscribe_watchlist(self) -> None`:

      - `await self.subscriber.subscribe_underlying(symbol, priority=SubscriptionPriority.MEDIUM)`
    - Log: `market_data.watchlist_subscribed` with count

    `async def subscribe_underlying(self, symbol: str, priority: SubscriptionPriority = SubscriptionPriority.MEDIUM) -> Ticker | None`:
    - Delegate to `self.subscriber.subscribe_underlying(symbol, priority)`

    `async def subscribe_option(self, contract: Option, priority: SubscriptionPriority = SubscriptionPriority.LOW) -> Ticker | None`:
    - Delegate to `self.subscriber.subscribe_option(contract, priority)`

    `async def unsubscribe(self, con_id: int) -> bool`:
    - Delegate to `self.subscriber.unsubscribe(con_id)`

    `def _on_pending_tickers(self, tickers: set) -> None`:
    - This is called by ib_async's event loop when ANY subscribed ticker has new data
    - For each ticker in tickers:
      - If `ticker.contract is None`: skip
      - Update last seen: `self.subscriber.update_last_seen(ticker.contract.conId)`
      - Create `QuoteSnapshot.from_ticker(ticker)` -- always, for all contract types
      - `asyncio.create_task(self.distributor.publish_quote(snapshot))`
      - `self.writer.buffer_quote(snapshot)` -- synchronous buffer, no await
      - If `ticker.contract.secType == "OPT"` and `ticker.modelGreeks is not None`:
        - Create `GreeksSnapshot.from_ticker(ticker)`
        - If greeks_snapshot is not None:
          - `asyncio.create_task(self.distributor.publish_greeks(greeks_snapshot))`
          - `self.writer.buffer_greeks(greeks_snapshot)` -- synchronous buffer

    `async def start(self) -> None`:
    - Start the writer: `await self.writer.start()`
    - Subscribe to watchlist: `await self.subscribe_watchlist()`
    - Log: `market_data.started`

    `async def stop(self) -> None`:
    - Unhook event: `self.ib.pendingTickersEvent -= self._on_pending_tickers`
    - Stop writer (flushes remaining data): `await self.writer.stop()`
    - Log: `market_data.stopped`
