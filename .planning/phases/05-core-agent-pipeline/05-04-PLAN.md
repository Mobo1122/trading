  Create `src/trading/agents/risk_agent.py` with the following components:

  1. **RiskAgentDeps dataclass**:
     - `risk_manager: RiskManager` (Phase 3 deterministic risk engine)
     - `session_factory: Any` (for DB access if needed)
     - `trade_proposals: list[dict]` (strategist output proposals from pipeline state)
     - `settings: Settings`

  2. **risk_agent = Agent(...)** definition:
     - `output_type=RiskManagerOutput`
     - `deps_type=RiskAgentDeps`
     - `instructions`: System prompt:
       "You are an options trading risk manager. For each trade proposal:
       1. FIRST: Run the deterministic risk check tool -- this is non-negotiable, every proposal must pass deterministic rules
       2. THEN: Provide your qualitative risk assessment considering market conditions, strategy appropriateness, and overall portfolio impact
       3. Score risk 1-10 (1=lowest risk, 10=highest risk)
       4. A proposal is approved ONLY IF: deterministic check passes AND your risk score is <= 7
       5. NEVER approve a proposal that failed the deterministic risk check, regardless of your own assessment
       Your role is to ADD a layer of judgment on top of hard rules, not to override them."
     - `model_settings=ModelSettings(temperature=0.1, max_tokens=2000)`

  3. **Tools**:

     **check_deterministic_risk(ctx: RunContext[RiskAgentDeps], proposal_json: str) -> str**:
     - Parses proposal_json into a dict, constructs a TradeProposal from the StrategyProposal data:
       - Map ProposedLeg fields to TradeLeg fields (symbol, sec_type="OPT", action, quantity, right, strike, expiry)
       - Set strategy_type from StrategyProposal
       - Set max_loss from StrategyProposal
       - Set estimated_greeks as GreeksImpact(delta=0, gamma=0, theta=0, vega=0) -- placeholder, actual Greeks computed by risk engine
       - Set account_value from a reasonable default or deps
     - Calls `await ctx.deps.risk_manager.check_trade(trade_proposal)`
     - Returns JSON of RiskDecision (approved, violated_rule, details)
     - Wrap in try/except: if risk manager is unreachable, return rejected decision with RISK_MANAGER_UNAVAILABLE

     **get_trade_proposals(ctx: RunContext[RiskAgentDeps]) -> str**:
     - Returns JSON of deps.trade_proposals
     - Gives the LLM the full list of proposals to evaluate

  4. **run_risk_agent helper function**:
     ```python
     async def run_risk_agent(
         deps: RiskAgentDeps,
         model: str | None = None,
         usage_limits: UsageLimits | None = None,
     ) -> tuple[RiskManagerOutput, Usage, list]:
     ```
     - Default UsageLimits: request_limit=10, response_tokens_limit=4000
     - Prompt: "Evaluate the following trade proposals against risk rules: {summary}. For EACH proposal, first run the deterministic risk check, then provide your assessment."
     - Returns (result.output, result.usage(), result.all_messages())
     - Log: num approved, num rejected, token usage

     - `trade_proposals: list[dict]` (original proposals for cross-reference)

       1. Use the submit_trade tool to place the order via IB
       2. Record the result (order_id, status, any errors)
       3. If submission fails, log the error but continue with remaining trades
       You are the final stage -- only execute trades that have been explicitly approved by the risk manager. Do not modify trade parameters."
     - `model_settings=ModelSettings(temperature=0.0, max_tokens=1500)` -- lowest temperature for executor, pure execution

  3. **Tools**:

     **submit_trade(ctx: RunContext[ExecutorDeps], proposal_json: str) -> str**:
     - Parses proposal_json, constructs a TradeProposal from the StrategyProposal data (same mapping as risk_agent)
     - Calls `await ctx.deps.execution_service.submit_order(trade_proposal)`
     - Returns JSON with order_id, status, details
     - Wrap in try/except: on failure, return status="failed" with error message
     - IMPORTANT: submit_order() internally calls evaluate_with_failsafe() again -- this is the double-check that the deterministic risk gate is non-bypassable even if the LLM agent misbehaves

     **get_approved_trades(ctx: RunContext[ExecutorDeps]) -> str**:
     - Returns JSON of deps.approved_assessments cross-referenced with deps.trade_proposals
     - Only includes proposals where assessment.approved is True

  4. **run_executor helper function**:
     ```python
     async def run_executor(
         deps: ExecutorDeps,
         model: str | None = None,
         usage_limits: UsageLimits | None = None,
     ) -> tuple[ExecutorOutput, Usage, list]:
     ```
     - Default UsageLimits: request_limit=10, response_tokens_limit=2000
     - Prompt: "Execute the following approved trades: {summary}. Submit each trade and report results."
     - Returns (result.output, result.usage(), result.all_messages())
     - Log: num submitted, num failed, token usage
