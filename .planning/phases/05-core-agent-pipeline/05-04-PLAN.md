       "You are an options trading risk manager. For each trade proposal:
       1. FIRST: Run the deterministic risk check tool -- this is non-negotiable, every proposal must pass deterministic rules
       2. THEN: Provide your qualitative risk assessment considering market conditions, strategy appropriateness, and overall portfolio impact
       3. Score risk 1-10 (1=lowest risk, 10=highest risk)
       4. A proposal is approved ONLY IF: deterministic check passes AND your risk score is <= 7
       5. NEVER approve a proposal that failed the deterministic risk check, regardless of your own assessment
       Your role is to ADD a layer of judgment on top of hard rules, not to override them."
     - `model_settings=ModelSettings(temperature=0.1, max_tokens=2000)`

  3. **Tools**:

     **get_contract_greeks(ctx: RunContext[RiskAgentDeps], symbol: str, strike: float, expiry: str, right: str) -> str**:
     - Looks up real-time Greeks from the Phase 2 Redis market data cache for a specific option contract.
     - Redis stores Greeks in HSET keys with pattern `mktdata:latest:greeks:{con_id}` (see RedisDistributor.GREEKS_HASH).
       Each HSET contains the GreeksSnapshot fields: symbol, con_id, implied_vol, delta, gamma, theta, vega, und_price, timestamp.
     - Since ProposedLeg has symbol/strike/expiry/right but NOT con_id, the tool must:
       a. Use `SCAN 0 MATCH mktdata:latest:greeks:*` to iterate over all cached Greeks keys.
       b. For each key, `HGETALL` and check if the stored `symbol` field matches the requested symbol.
         (This is efficient because only actively-subscribed contracts have cached Greeks -- typically <100 keys.)
       c. If a matching symbol is found, return JSON with delta, gamma, theta, vega values.
       d. If multiple matches for the same symbol (different con_ids), log them all and return the first match.
         NOTE: This is a known simplification -- matching by symbol alone doesn't distinguish between
         contracts at different strikes/expiries. A future enhancement can add con_id resolution
         via ContractResolver.qualify_options() for exact matching. For now, same-symbol Greeks
         provide a reasonable approximation for portfolio-level exposure checks.
     - If no match found, return JSON with `{"found": false, "delta": 0, "gamma": 0, "theta": 0, "vega": 0}`
       and log a structlog warning: `"greeks.cache_miss"` with symbol, strike, expiry, right.
     - Wrap in try/except: on Redis errors, return the zero fallback with a warning log.

     **check_deterministic_risk(ctx: RunContext[RiskAgentDeps], proposal_json: str) -> str**:
     - Parses proposal_json into a dict, constructs a TradeProposal from the StrategyProposal data:
       - Map ProposedLeg fields to TradeLeg fields (symbol, sec_type="OPT", action, quantity, right, strike, expiry)
       - Set strategy_type from StrategyProposal
       - Set max_loss from StrategyProposal
       - **Fetch real Greeks**: For EACH leg in the proposal, call the internal `_lookup_greeks` helper
         (an async function, NOT a PydanticAI tool) that performs the same Redis lookup as get_contract_greeks.
         Aggregate the per-leg Greeks into a single GreeksImpact:
           - For each leg: multiply the per-contract delta/gamma/theta/vega by leg.quantity
             (negate for SELL actions since selling reduces exposure)
           - Sum across all legs to get net GreeksImpact(delta=sum_delta, gamma=sum_gamma, theta=sum_theta, vega=sum_vega)
         If Redis lookup fails or returns no data for a leg, use zeros for that leg and log a warning.
         This ensures the Phase 3 RISK-02 Greek exposure check (DELTA_EXPOSURE, GAMMA_EXPOSURE,
         THETA_EXPOSURE, VEGA_EXPOSURE) evaluates actual portfolio impact, not placeholder zeros.
       - Set account_value from a reasonable default or deps
     - Calls `await ctx.deps.risk_manager.check_trade(trade_proposal)`
     - Returns JSON of RiskDecision (approved, violated_rule, details)
     - Wrap in try/except: if risk manager is unreachable, return rejected decision with RISK_MANAGER_UNAVAILABLE

     **get_trade_proposals(ctx: RunContext[RiskAgentDeps]) -> str**:
     - Returns JSON of deps.trade_proposals
     - Gives the LLM the full list of proposals to evaluate

  4. **_lookup_greeks helper** (private async function, not a tool):
     ```python
     async def _lookup_greeks(redis_client, symbol: str, strike: float, expiry: str, right: str) -> dict:
     ```
     - Shared logic between get_contract_greeks tool and check_deterministic_risk tool.
     - Performs the Redis SCAN + HGETALL pattern described in get_contract_greeks.
     - Returns dict with keys: found (bool), delta, gamma, theta, vega (all float).
     - Handles Redis errors gracefully, returning zero fallback.
