     ```python
     async def log_agent_decision(
         session_factory,
         run_id: str,
         agent_name: str,
         output: BaseModel | None,
         messages: list | None,
         usage: Any | None,
         duration_ms: int | None = None,
     ```

       - `request_tokens`: From usage.request_tokens if usage provided
       - `response_tokens`: From usage.response_tokens if usage provided
       - `model_name`: From usage if available (check for model_name attribute)
       - `duration_ms`: from parameter
       - `error`: from parameter
     - Persists via session_factory using the get_session pattern from existing code
     - Entire function wrapped in try/except -- logging errors are non-fatal (log warning via structlog, never crash pipeline)
