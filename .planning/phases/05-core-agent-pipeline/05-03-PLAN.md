     - `output_type=StrategistOutput`
     - `deps_type=StrategistDeps`
     - `instructions`: System prompt:
       "You are an options strategist. Given trading opportunities identified by the scanner, construct complete trade proposals. For each opportunity:
       1. Use the option chain tool to get REAL available strikes and expirations -- NEVER invent strike prices
       2. Select an appropriate strategy type based on the opportunity signal (e.g., high IV -> sell premium via iron condor or credit spread; low IV -> buy premium via debit spread or long options; earnings -> straddle/strangle)
       3. Choose specific strikes and expirations from the available chain
       4. Size the trade within risk limits (max contracts, max dollars, max portfolio percentage)
       5. Calculate max loss and max profit for the proposed strategy
       6. Estimate probability of profit based on the Greeks and IV data
       If the option chain doesn't have suitable strikes for a given opportunity, skip it with an explanation. Quality over quantity -- only propose trades with clear edge."
     - `model_settings=ModelSettings(temperature=0.1, max_tokens=2000)`

  3. **Tools** (decorated with @strategist_agent.tool):

     **get_option_chain(ctx: RunContext[StrategistDeps], symbol: str) -> str**:
     - Uses `ctx.deps.contract_resolver` to call `resolve_options(symbol)` or the equivalent method to get available strikes and expirations
     - Returns JSON with: `{"symbol": ..., "expirations": [...], "strikes": [...], "rights": ["C", "P"]}`
     - If the resolver needs IB connection and it's not available, return a clear error message
     - Truncate large chains to a reasonable subset (e.g., strikes within 20% of current price, nearest 6 expirations)

     **get_current_price(ctx: RunContext[StrategistDeps], symbol: str) -> str**:
     - Reads latest quote from Redis via HGET `market_data:{symbol}`
     - Returns JSON with bid, ask, last, mid_price
     - If no data, return error JSON

     **get_risk_limits(ctx: RunContext[StrategistDeps]) -> str**:
     - Returns JSON with position limits from deps.risk_limits:
       max_position_pct, max_contracts, max_dollars, account_value
     - This lets the LLM size trades within constraints

     **get_opportunities(ctx: RunContext[StrategistDeps]) -> str**:
     - Returns JSON of deps.opportunities list
     - This passes the scanner output to the strategist

  4. **run_strategist helper function**:
     ```python
     async def run_strategist(
         deps: StrategistDeps,
     ```

     - Runs agent with deps and usage_limits (default: UsageLimits(request_limit=15, response_tokens_limit=4000) -- higher request_limit because strategist makes more tool calls)
     - Returns tuple of (result.output, result.usage(), result.all_messages())
     - Log via structlog: num proposals, total max_loss across proposals, token usage
