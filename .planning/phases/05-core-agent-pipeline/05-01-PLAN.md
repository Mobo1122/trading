  6. Create `src/trading/agents/models.py` with ALL shared output contracts:

     **Opportunity** (scanner output per opportunity):
     - `symbol: str`
     - `signal_type: str` (e.g., "iv_rank_high", "earnings_approaching", "technical_breakout")
     - `confidence: float` (0-1)
     - `iv_rank: float | None`
     - `iv_percentile: float | None`
     - `current_price: float | None`
     - `days_to_earnings: int | None`
     - `reasoning: str` (why this opportunity was flagged)

     **ScannerOutput**:
     - `opportunities: list[Opportunity]`
     - `symbols_scanned: int`
     - `reasoning: str` (overall scan summary)

     **ProposedLeg** (strategist output per leg):
     - `symbol: str`
     - `right: str` (C or P)
     - `strike: float`
     - `expiry: str` (YYYYMMDD)
     - `action: str` (BUY or SELL)
     - `quantity: int`
     - `estimated_price: float | None`

     **StrategyProposal** (strategist output per trade):
     - `symbol: str`
     - `strategy_type: str` (e.g., "iron_condor", "vertical_spread", "covered_call")
     - `legs: list[ProposedLeg]`
     - `max_loss: float`
     - `max_profit: float`
     - `probability_of_profit: float` (0-1, Field(ge=0, le=1))
     - `reasoning: str`

     **StrategistOutput**:
     - `proposals: list[StrategyProposal]`
     - `reasoning: str`

     **RiskAssessment** (risk agent output per proposal):
     - `proposal_id: str`
     - `deterministic_approved: bool`
     - `deterministic_details: str`
     - `llm_risk_score: float` (1-10, 1=low risk, 10=high risk)
     - `llm_risk_reasoning: str`
     - `approved: bool` (final decision: deterministic AND llm acceptable)
     - `reasoning: str`

     **RiskManagerOutput**:
     - `assessments: list[RiskAssessment]`
     - `reasoning: str`

     **ExecutionResult** (executor output per trade):
     - `proposal_id: str`
     - `order_id: str | None`
     - `status: str` (e.g., "submitted", "failed", "skipped")
     - `details: str`

     **ExecutorOutput**:
     - `results: list[ExecutionResult]`
     - `reasoning: str`

     **PipelineResult** (final pipeline output):
     - `run_id: str`
     - `scanner_output: ScannerOutput | None`
     - `strategist_output: StrategistOutput | None`
     - `risk_output: RiskManagerOutput | None`
     - `executor_output: ExecutorOutput | None`
     - `completed_stages: list[str]`
     - `aborted_at: str | None` (stage name if pipeline stopped early)

     Use Pydantic Field descriptions on all fields for LLM schema generation. Import datetime from standard library. All models inherit from pydantic.BaseModel.

     - `async def create_checkpointer(conn_string: str) -> AsyncPostgresSaver`:
       Import from `langgraph.checkpoint.postgres.aio`. Uses `AsyncPostgresSaver.from_conn_string(conn_string)`. Calls `await checkpointer.setup()` to create checkpoint tables. Returns the checkpointer.
     - NOTE: conn_string must be plain `postgresql://` (psycopg), NOT `postgresql+asyncpg://`. The function should validate this and raise ValueError if `+asyncpg` is found in the string.
