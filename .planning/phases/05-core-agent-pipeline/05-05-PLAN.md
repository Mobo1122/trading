  Create `src/trading/agents/pipeline.py` with the following components:

  1. **PipelineDeps dataclass** (contains all dependencies needed by all agents):
     - `iv_engine: Any`
     - `earnings_calendar: Any`
     - `contract_resolver: Any`
     - `risk_manager: Any`
     - `execution_service: Any`
     - `redis_client: Any`
     - `session_factory: Any`
     - `settings: Settings`
     - `account_value: float = 100000.0` (default, should be updated from IB account data)

  2. **Node functions** (each wraps a PydanticAI agent run):

     **async def scan_node(state: PipelineState, deps: PipelineDeps) -> dict**:
     - Construct ScannerDeps from deps and state["watchlist"]
     - Get model name from `deps.settings.agents.get_model("scanner")`
     - Call `run_scanner(scanner_deps, model=model_name)`
     - Convert ScannerOutput.opportunities to list of dicts via `.model_dump()`
     - Return dict update: `{"opportunities": [opp dicts], "scanner_reasoning": output.reasoning}`
     - On error: return `{"opportunities": [], "scanner_reasoning": f"Scanner error: {e}", "aborted_at": "scanner"}`

     **async def strategist_node(state: PipelineState, deps: PipelineDeps) -> dict**:
     - Construct StrategistDeps from deps, state["opportunities"], risk_limits from settings
     - Call `run_strategist(strategist_deps, model=model_name)`
     - Convert proposals to list of dicts
     - Return: `{"trade_proposals": [proposal dicts], "strategist_reasoning": output.reasoning}`

     **async def risk_node(state: PipelineState, deps: PipelineDeps) -> dict**:
     - Construct RiskAgentDeps from deps, state["trade_proposals"]
     - Call `run_risk_agent(risk_deps, model=model_name)`
     - Convert assessments to list of dicts
     - Return: `{"risk_assessments": [assessment dicts], "risk_reasoning": output.reasoning}`

     **async def executor_node(state: PipelineState, deps: PipelineDeps) -> dict**:
     - Filter risk_assessments for approved only
     - Construct ExecutorDeps from deps with approved assessments and trade_proposals
     - Call `run_executor(executor_deps, model=model_name)`
     - Convert results to list of dicts
     - Return: `{"execution_results": [result dicts], "executor_reasoning": output.reasoning}`

  3. **Routing functions**:

     **def route_after_scan(state: PipelineState) -> str**:
     - If `state.get("opportunities")` is non-empty: return `"strategist"`
     - Else: return `END` (nothing to work on)

     **def route_after_risk(state: PipelineState) -> str**:
     - If any assessment in `state.get("risk_assessments", [])` has `approved=True`: return `"executor"`
     - Else: return `END` (nothing approved)

  4. **create_pipeline factory function**:
     ```python
     async def create_pipeline(
         deps: PipelineDeps,
         checkpointer=None,
     ) -> CompiledGraph:
     ```
     - Build StateGraph(PipelineState)
     - Add nodes: "scanner", "strategist", "risk_manager", "executor"
     - Each node function needs access to deps. Use functools.partial or a closure to bind deps into the node functions, since LangGraph node functions receive only (state) as arg.
       Pattern: `workflow.add_node("scanner", lambda state: scan_node(state, deps))`
       Or use functools.partial.
     - Add edges:
       - START -> "scanner"
       - "scanner" -> conditional(route_after_scan) -> "strategist" or END
       - "strategist" -> "risk_manager"
       - "risk_manager" -> conditional(route_after_risk) -> "executor" or END
       - "executor" -> END
     - If checkpointer is None and deps.settings.agents.checkpoint_conn_string:
       - Create checkpointer via `create_checkpointer(conn_string)`
     - Compile with checkpointer: `workflow.compile(checkpointer=checkpointer)`
     - Return compiled graph

  5. **run_pipeline convenience function**:
     ```python
     async def run_pipeline(
         graph: CompiledGraph,
         watchlist: list[str],
         run_id: str | None = None,
     ) -> PipelineState:
     ```
     - Generate run_id if not provided (uuid4)
     - Create initial state: `{"watchlist": watchlist, "opportunities": [], "trade_proposals": [], "risk_assessments": [], "execution_results": [], "scanner_reasoning": "", "strategist_reasoning": "", "risk_reasoning": "", "executor_reasoning": "", "run_id": run_id, "aborted_at": ""}`
     - Config: `{"configurable": {"thread_id": run_id}}`
     - Call `result = await graph.ainvoke(initial_state, config=config)`
     - Log via structlog: run_id, completed stages, num opportunities, num proposals, num approved, num executed
     - Return result as PipelineState

  IMPORTANT: Node functions must handle errors gracefully. If any agent run fails, the node should return partial state with error info in reasoning, not crash the pipeline.

  IMPORTANT: Node functions that wrap async PydanticAI agents must themselves be async. LangGraph supports async node functions natively.
