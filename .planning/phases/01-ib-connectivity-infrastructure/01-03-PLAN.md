  <name>Task 1: IB Connection Manager with auto-reconnect</name>
  <files>

  <action>
    Implement `IBConnectionManager` in `src/trading/core/connection.py` following the research Pattern 2, with these enhancements:

    **Constructor `__init__(self, settings: Settings)`:**
    - Store settings reference
    - Create `self.ib = IB()` -- single instance for entire app lifecycle (research anti-pattern: never create per-request)
    - Create `self._connected = asyncio.Event()` for connection state signaling
    - Create `self._shutdown = False` flag
    - Create `self._reconnect_count = 0` counter for monitoring
    - Attach event handlers EXACTLY ONCE here (research Pitfall 2 -- CRITICAL):
      - `self.ib.disconnectedEvent += self._on_disconnected`
      - `self.ib.connectedEvent += self._on_connected`

    **`async connect(self)`:**
    - Public entry point for initial connection
    - Calls `_do_connect()`
    - Logs initial connection attempt with mode (paper/live) and target host:port

    **`async _do_connect(self)`:**
    - Reconnection loop with exponential backoff
    - While not `self._shutdown`:
      - Attempt connection via `self.ib.connectAsync(host, port, clientId, timeout)`
      - Port comes from `self.settings.trading.ib_port` (derived from mode, NOT hardcoded)
      - On success: set `self._connected`, log success, return
      - On failure: calculate delay = `min(reconnect_delay * (2 ** attempt), reconnect_max_delay)`, add jitter (random 0-1 second), log warning with attempt number and retry delay, sleep, increment attempt
      - Respect `max_reconnect_attempts` if > 0 (0 = infinite)

    **`_on_connected(self)`:**
    - Set `self._connected` event
    - Reset `self._reconnect_count = 0`
    - Log info: "ib.connected"

    **`_on_disconnected(self)`:**
    - Clear `self._connected` event
    - If not `self._shutdown`:
      - Increment `self._reconnect_count`
      - Log warning: "ib.disconnected", include reconnect_count
      - Schedule reconnection: `asyncio.create_task(self._do_connect())`
    - If `self._shutdown`: log info "ib.disconnected (shutdown)"

    **`async disconnect(self)`:**
    - Set `self._shutdown = True`
    - Call `self.ib.disconnect()`
    - Log info: "ib.shutdown_complete"

    **`async wait_connected(self, timeout: float | None = None) -> bool`:**
    - Wait for `self._connected` event with optional timeout
    - Returns True if connected, False if timeout expired
    - Use `asyncio.wait_for` wrapping `self._connected.wait()`

    **Properties:**
    - `is_connected -> bool`: return `self._connected.is_set()`
    - `reconnect_count -> int`: return `self._reconnect_count`

    Export `IBConnectionManager` from `core/__init__.py`.

    Use `structlog.get_logger()` for all logging. Bind context: `component="ib_connection"`, `mode=settings.trading.mode`.
  </action>
  <verify>
    `uv run python -c "from trading.core import IBConnectionManager; print('Import OK')"` succeeds.
    `uv run python -c "from trading.core.connection import IBConnectionManager; from trading.config import Settings; s = Settings(); m = IBConnectionManager(s); print(f'Manager created, port={s.trading.ib_port}')"` prints "Manager created, port=4002".
  </verify>
  <done>
    IBConnectionManager is importable, instantiable with Settings, and has all connection lifecycle methods. Event handlers attached once in constructor. Exponential backoff reconnection with jitter.
