  1. Create `src/trading/dashboard/routes/greeks.py` with APIRouter (prefix="/api/greeks", tags=["greeks"]):

     - `GET /api/greeks`: Returns portfolio-level aggregated Greeks.
       - Scan Redis for all keys matching `mktdata:latest:greeks:*` using SCAN (not KEYS, to avoid blocking). For each key, HGETALL to get delta, gamma, theta, vega.
       - Sum all deltas, gammas, thetas, vegas across all option contracts.
       - Return `GreeksResponse` with `is_portfolio=True`.
       - Get Redis from `request.app.state.redis`.

     - `GET /api/greeks/positions`: Returns per-position Greeks breakdown.
       - Same Redis scan but return list of `GreeksResponse` with symbol set.

  2. Create `src/trading/dashboard/routes/trades.py` with APIRouter (prefix="/api/trades", tags=["trades"]):

     - `GET /api/trades/history`: Returns paginated trade history with reasoning chains.
       - Query params: `limit: int = Query(default=50, le=200)`, `offset: int = Query(default=0, ge=0)`.
       - Query `Order` table where `current_state == "FILLED"`, ordered by `updated_at DESC`, with limit/offset.
       - For each order that has a `proposal_id`, query `AgentDecisionLog` where `run_id == order.proposal_id`, ordered by `stage_order ASC`.
       - Build list of `TradeHistoryItem` with `reasoning_chain` populated from the decision log entries (agent_name, reasoning, output_summary, duration_ms).
       - The join is: `Order.proposal_id == AgentDecisionLog.run_id`. This links each trade to the full pipeline run that produced it.
       - Return `{"trades": list[TradeHistoryItem], "total": count}` where count is total filled orders (for pagination).
       - Get async session from `get_db_session` dependency.

     - `GET /api/trades/{order_id}`: Returns single trade with full reasoning chain.
       - Query Order by id. If not found, return 404.
       - Query reasoning chain by proposal_id -> run_id.
       - Return single `TradeHistoryItem`.

  3. Update `src/trading/dashboard/server.py` to include both new routers:
     - `app.include_router(greeks_router)`
     - `app.include_router(trades_router)`
