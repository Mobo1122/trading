       - **Redis check**: Call `await redis.ping()` wrapped in try/except. If ping succeeds, redis_connected=True. If fails, redis_connected=False.
       - **DB check**: Try executing `SELECT 1` via async session. If succeeds, db_connected=True. If fails, db_connected=False.
       - **IB check**: The dashboard server is a separate process from TradingApp and does not have direct IB access. Instead, check Redis for a health key: `dashboard:ib_status`.        - **Data freshness**: Get all keys matching `mktdata:latest:quote:*` via Redis SCAN. For each, HGET the "timestamp" field. Compute seconds since that timestamp. Return dict mapping symbol to staleness_seconds.
       - **Pipeline status**: Check Redis key `dashboard:pipeline_status` (published by DashboardPublisher, defaults to "idle" if not set).
       - **Last heartbeat**: Check Redis key `dashboard:heartbeat` for last TradingApp heartbeat timestamp (published by DashboardPublisher).
       - **Per-agent last-seen (NEW)**: Query `AgentDecisionLog` for the most recent `timestamp` per `agent_name`. Use a SQLAlchemy query:
         ```python
         from sqlalchemy import func, select
         from trading.db.models import AgentDecisionLog

         stmt = (
             select(
                 AgentDecisionLog.agent_name,
                 func.max(AgentDecisionLog.timestamp).label("last_seen"),
             )
             .group_by(AgentDecisionLog.agent_name)
         )
         result = await session.execute(stmt)
         agent_last_seen = {
             row.agent_name: row.last_seen.isoformat()
             for row in result.all()
         }
         ```
         This gives per-agent visibility: e.g., {"scanner": "2026-04-04T12:00:00Z", "strategist": "2026-04-04T12:00:01Z", ...}
