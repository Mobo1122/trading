  <files>src/trading/dashboard/routes/positions.py, src/trading/dashboard/server.py</files>
  <action>
  1. Create `src/trading/dashboard/routes/positions.py` with an APIRouter (prefix="/api/positions", tags=["positions"]):

     - `GET /api/positions`: Returns list of current positions.
       - Since there's no dedicated positions table, derive positions from IB portfolio data cached in Redis. The approach: query Redis for all keys matching `dashboard:positions` (a JSON blob we expect the trading system to publish). If not available, fall back to querying filled orders from the database and grouping by symbol to compute net positions.
       - For real-time prices, look up each symbol in Redis HGET `mktdata:latest:quote:{symbol}` to get current bid/ask/last.
       - Compute unrealized P&L per position: `(current_price - avg_cost) * quantity * multiplier` where multiplier=100 for options.
       - Return `list[PositionResponse]`.

     - `GET /api/portfolio`: Returns portfolio-level summary.
       - Aggregate across all positions: total market value, total unrealized PnL, total realized PnL (from execution_records in DB).
       - Return `PortfolioSummary`.

     Both endpoints get Redis client from `request.app.state.redis` and session factory from `request.app.state.session_factory`. Use the `get_db_session` dependency from server.py for DB access.

  2. Update `src/trading/dashboard/server.py` to include the positions router:
     - Import the positions router and call `app.include_router(positions_router)` in `create_app()`.
  </action>
