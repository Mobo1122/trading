  <action>
  1. Create `dashboard/src/types/index.ts` with TypeScript interfaces matching backend Pydantic models:
     - `Position`: symbol (string), secType (string), quantity (number), avgCost (number), currentPrice (number), unrealizedPnl (number), unrealizedPnlPct (number), marketValue (number).
     - `PortfolioSummary`: totalMarketValue (number), totalUnrealizedPnl (number), totalRealizedPnl (number), netLiquidation (number).
     - `Greeks`: delta (number), gamma (number), theta (number), vega (number), symbol (string | null), isPortfolio (boolean).
     - `ReasoningStep`: agent (string), reasoning (string | null), outputSummary (string | null), durationMs (number | null).
     - `TradeHistoryItem`: orderId (string), symbol (string), action (string), quantity (number), fillPrice (number | null), commission (number | null), createdAt (string), updatedAt (string), reasoningChain (ReasoningStep[] | null).
     - `HealthStatus`: ibConnected (boolean), dbConnected (boolean), redisConnected (boolean), dataFreshness (Record<string, number>), lastHeartbeat (string | null), pipelineStatus (string).
     - `ScenarioRequest`: underlyingChangePct (number), ivChangePct (number), daysForward (number), riskFreeRate (number).
     - `ScenarioResponse`: currentValue (number), scenarioValue (number), pnl (number), pnlPercent (number), perPosition (any[]).
     - `WSMessage`: type (string), channel (string | null), data (any).

     Use camelCase for TypeScript (the API client will transform snake_case responses).

  2. Create `dashboard/src/lib/api.ts`:
     - `const API_URL = process.env.NEXT_PUBLIC_API_URL || "http://localhost:8000"`
     - Helper function `async function fetchApi<T>(path: string, options?: RequestInit): Promise<T>` that prepends API_URL, sets Content-Type, and transforms snake_case response keys to camelCase recursively.
     - Export convenience functions: `getTradeHistory(limit?, offset?)`, `getHealth()`, `runScenario(request: ScenarioRequest)`.

  3. Create `dashboard/src/stores/positions-store.ts`:
     - Zustand store with state: `positions: Record<string, Position>`, `portfolioSummary: PortfolioSummary | null`.
     - Actions: `updatePosition(pos: Position)` (upserts into positions map, recalculates portfolio PnL), `setPositions(positions: Position[])` (replaces all), `setPortfolioSummary(summary: PortfolioSummary)`.

  4. Create `dashboard/src/stores/greeks-store.ts`:
     - Zustand store with state: `portfolioGreeks: Greeks | null`, `positionGreeks: Record<string, Greeks>`.
     - Actions: `setPortfolioGreeks(greeks: Greeks)`, `updatePositionGreeks(symbol: string, greeks: Greeks)`.

  5. Create `dashboard/src/stores/health-store.ts`:
     - Zustand store with state: `health: HealthStatus | null`, `lastUpdated: string | null`.
     - Actions: `setHealth(status: HealthStatus)`.

  6. Create `dashboard/src/lib/ws-client.ts`:
     - `const WS_URL = process.env.NEXT_PUBLIC_WS_URL || "ws://localhost:8000/ws"`
     - `const RECONNECT_DELAY = 3000`
     - `const PING_INTERVAL = 30000`
     - Class `DashboardWebSocket`:
       - Private fields: `ws: WebSocket | null`, `reconnectTimer`, `pingTimer`, `isIntentionalClose: boolean`.
       - `connect()`: Create WebSocket. On open: subscribe to channels ["positions", "health", "portfolio_greeks"]. Start ping interval.
       - `onmessage` handler: Parse JSON. Route by message type:
         - "snapshot" / "channel_snapshot": Call appropriate store's set method based on channel.
         - "update": Call appropriate store's update method based on channel. Route "positions" to usePositionsStore, "health" to useHealthStore, "portfolio_greeks" to useGreeksStore, "quotes:*" to usePositionsStore for price updates.
         - "pong": no-op (heartbeat response).
       - `onclose`: Clear ping interval. If not intentional close, schedule reconnect after RECONNECT_DELAY.
       - `onerror`: Close the socket (triggers onclose reconnect logic).
       - `disconnect()`: Set intentional close flag. Close socket. Clear timers.
       - `subscribe(channel: string)`: Send subscribe message if connected.
       - `unsubscribe(channel: string)`: Send unsubscribe message if connected.
     - Export singleton: `export const dashboardWS = new DashboardWebSocket()`.

  7. Create `dashboard/src/hooks/use-websocket.ts`:
     - "use client" directive.
     - Import `dashboardWS` from ws-client.
     - `useWebSocket()` hook: On mount (useEffect), call `dashboardWS.connect()`. On unmount, call `dashboardWS.disconnect()`. Return the dashboardWS instance.

  8. Replace `dashboard/src/app/layout.tsx`:
     - "use client" at top (needed for useWebSocket hook).
     - Import useWebSocket hook.
     - Create a `WebSocketProvider` client component that calls `useWebSocket()` and renders children.
     - Root layout with:
       - Dark theme via `<html className="dark">` and `<body className="bg-background text-foreground">`.
       - Left sidebar navigation with links: Positions (/positions), Greeks (/greeks), Trades (/trades), Health (/health), Scenarios (/scenarios). Use simple `<a>` or Next.js `<Link>` tags styled with Tailwind.
       - Header showing "Trading Dashboard" title.
       - Main content area rendering `{children}` wrapped in the WebSocketProvider.
     - Use Tailwind grid: `grid grid-cols-[240px_1fr]` for sidebar + content layout.
     - Active link highlighting based on current pathname (use `usePathname` from `next/navigation`).

  9. Replace `dashboard/src/app/page.tsx`:
     - Simple redirect to /positions (the main view). Use `redirect("/positions")` from `next/navigation`.
     - Or render a brief dashboard home with links to each section.
