  1. Create `src/trading/alerts/slack.py` with `SlackNotifier`:
     - Constructor takes `webhook_url: str`.
     - Create `AsyncWebhookClient(url=webhook_url)` as `self._client`.
     - `async send(channel: str, data: dict) -> None`: Build a text fallback and optional Block Kit blocks based on channel type:
       - `alerts:trade_executed`: Green header, symbol, strategy, fill price, quantity.
       - `alerts:risk_breach`: Red header with breach details.
       - `alerts:circuit_breaker`: Red header with halt reason.
       - `alerts:system_error`: Red header with error message.
       - `alerts:approval_request`: Header with trade context (detailed -- used by Plan 05 for interactive buttons, but the basic notification goes here).
       - `alerts:approval_resolved`: Header with decision result.
       - Default: plain text with channel name and data summary.
     - Use `_build_blocks(channel, data) -> list[dict]` private method to construct Block Kit structures.
     - Wrap `self._client.send()` in try/except. Log warning on failure (non-fatal, matching project convention).
     - Use structlog with component="slack_notifier".

  2. Create `src/trading/alerts/sms.py` with `SMSNotifier`:
     - Constructor takes `account_sid: str`, `auth_token: str`, `from_number: str`, `to_number: str`, `cooldown_seconds: int = 300`.
     - `self._last_sent: dict[str, float] = {}` -- channel -> monotonic timestamp of last SMS for cooldown tracking.
     - `async send(channel: str, data: dict) -> None`:
       - Check cooldown: if `channel` in `self._last_sent` and `time.monotonic() - self._last_sent[channel] < self._cooldown`, skip (log debug "sms.cooldown_active").
       - Build a concise SMS body from channel + data (max 160 chars for single SMS segment; truncate with "..." if longer).
       - POST to `https://api.twilio.com/2010-04-01/Accounts/{account_sid}/Messages.json` using `httpx.AsyncClient` with `auth=(account_sid, auth_token)` and `data={"To": to_number, "From": from_number, "Body": body}`.
       - On success, update `self._last_sent[channel] = time.monotonic()`.
       - Wrap in try/except. Log warning on failure (non-fatal).
     - Use structlog with component="sms_notifier".

  3. Create `src/trading/alerts/router.py` with `AlertRouter`:
     - `CHANNELS` class variable: `["alerts:trade_executed", "alerts:trade_rejected", "alerts:risk_breach", "alerts:circuit_breaker", "alerts:system_error", "alerts:approval_request", "alerts:approval_resolved"]`
     - Constructor takes `redis: Any`, `slack_notifier: SlackNotifier | None`, `sms_notifier: SMSNotifier | None`, `config: AlertConfig`.
     - `async listen() -> None`: Subscribe to channels via `pubsub.subscribe(*self.CHANNELS)` (exact channels, not patterns). Iterate messages with `async for message in pubsub.listen()`. For each message with `type == "message"`, parse `json.loads(message["data"])`, call `await self._route(channel, data)`. Handle `asyncio.CancelledError` for clean shutdown (unsubscribe + close pubsub).
     - `async _route(channel: str, data: dict) -> None`:
       - If `self._slack` is not None and `self._config.slack_enabled`: `await self._slack.send(channel, data)`.
       - If `self._sms` is not None and `self._config.sms_enabled` and `channel in self._config.sms_channels`: `await self._sms.send(channel, data)`.
       - Each call wrapped individually in try/except with warning log (one notifier failure must not block the other).
     - Use structlog with component="alert_router".
