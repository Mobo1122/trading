<objective>
Build the Slack interactive button integration: a slack-bolt AsyncApp running in Socket Mode that handles approve/reject button clicks from Slack messages, resolves approvals via ApprovalManager, and updates the Slack message to show the decision. Also enhance SlackNotifier to send approval requests with Block Kit interactive buttons.

Purpose: This enables the user to approve or reject escalated trades directly from Slack without opening the dashboard, which is critical for time-sensitive trade decisions. Socket Mode eliminates the need for a public HTTP endpoint.

Output: `src/trading/alerts/slack_bot.py` with Socket Mode handler, enhanced SlackNotifier with Block Kit buttons, TradingApp wiring, and unit tests.

  1. Create `src/trading/alerts/slack_bot.py`:

     a. `create_slack_bot(bot_token: str, approval_manager: Any) -> AsyncApp`:
        - Create `AsyncApp(token=bot_token)` (from `slack_bolt.app.async_app`).
        - Register action handlers on the app:

        - `@app.action("approve_trade")` handler:
          - `await ack()` -- FIRST LINE, before any async work (3-second deadline).
          - Extract `approval_id = body["actions"][0]["value"]`.
          - Call `await approval_manager.resolve(approval_id, "approved")`.
          - Update the Slack message to show "Approved" status:
            ```python
            await client.chat_update(
                channel=body["channel"]["id"],
                ts=body["message"]["ts"],
                blocks=_build_resolved_blocks(body["message"]["blocks"], "approved"),
                text="Trade approved",
            )
            ```
          - Wrap post-ack work in try/except. Log errors as warnings (non-fatal after ack).

        - `@app.action("reject_trade")` handler:
          - `await ack()` -- FIRST LINE.
          - Extract `approval_id = body["actions"][0]["value"]`.
          - Call `await approval_manager.resolve(approval_id, "rejected")`.
          - Update message with "Rejected" status.
          - Same error handling pattern.

        - Return the app.

     b. `_build_resolved_blocks(original_blocks: list[dict], decision: str) -> list[dict]`:
        - Take the original message blocks and replace the actions block (type="actions") with a context block showing the resolution:
          - "approved": green checkmark text "Approved by user via Slack"
          - "rejected": red X text "Rejected by user via Slack"
          - "timed_out": gray clock text "Timed out - auto-rejected"
        - Keep the header and context/section blocks (trade details) unchanged.
        - Add a section with `mrkdwn` text showing the decision and timestamp.

     c. `async def start_socket_mode(app: AsyncApp, app_token: str) -> None`:
        - Create `AsyncSocketModeHandler(app, app_token)` (from `slack_bolt.adapter.socket_mode.async_handler`).
        - Call `await handler.start_async()`.
        - This runs indefinitely until cancelled.

     Use structlog with component="slack_bot".

  2. Enhance `src/trading/alerts/slack.py` SlackNotifier:

        - Section with fields: Symbol, Strategy Type, Max Loss ($), Max Profit ($)

        - Actions block with two buttons:
          - "Approve" button: `style="primary"`, `action_id="approve_trade"`, `value=data["approval_id"]`
          - "Reject" button: `style="danger"`, `action_id="reject_trade"`, `value=data["approval_id"]`
        - Context block showing requested_at timestamp.

     b. For `alerts:approval_resolved` channel, build a block showing the decision result (no buttons needed).

     c. Ensure the `send` method passes both `text` (fallback for notifications) and `blocks` (Block Kit) to `self._client.send()`.

     f. For all other channels: continue using the webhook client (no interactivity needed).

          ```python

                  webhook_url=self.settings.alerts.slack_webhook_url,

                  channel=self.settings.alerts.slack_channel,
              )
          ```

     d. In `connect_ib()`, after starting alert router:
        - Start Slack bot Socket Mode if bot_token and app_token are configured (non-critical):
          ```python
          if (self.settings.alerts.slack_enabled
              and self.settings.alerts.slack_bot_token
              and self.settings.alerts.slack_app_token
              and self.approval_manager is not None):
              try:
                  slack_app = create_slack_bot(
                      bot_token=self.settings.alerts.slack_bot_token,
                      approval_manager=self.approval_manager,
                  )
                  self._slack_bot_task = asyncio.create_task(
                      start_socket_mode(slack_app, self.settings.alerts.slack_app_token)
                  )
                  self.log.info("slack_bot.started")
              except Exception:
                  self.log.warning("slack_bot.start_failed", exc_info=True)
          ```

     e. In `shutdown()`, cancel Slack bot task (before alert router cancellation):
        ```python
        if self._slack_bot_task is not None:
            try:
                self._slack_bot_task.cancel()
                try:
                    await self._slack_bot_task
                except asyncio.CancelledError:
                    pass
            except Exception:
                self.log.warning("shutdown.slack_bot_failed", exc_info=True)
        ```
