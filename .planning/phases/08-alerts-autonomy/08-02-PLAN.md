  1. Create `src/trading/alerts/approval.py` with `ApprovalManager`:

     Constructor takes `redis: Any`, `timeout_seconds: int = 300`.
     - `self._redis = redis`
     - `self._timeout = timeout_seconds`
     - `self._pending: dict[str, asyncio.Future[str]] = {}` -- approval_id -> Future

     `async request_approval(approval_id: str, context: dict) -> str`:
     - Store approval state in Redis hash `approval:{approval_id}` with fields:
       - `status`: "pending"
       - `context`: `json.dumps(context)`
       - `requested_at`: `datetime.now(timezone.utc).isoformat()`
       - `timeout_at`: `(datetime.now(timezone.utc) + timedelta(seconds=self._timeout)).isoformat()`
     - Set TTL on the Redis key: `await self._redis.expire(f"approval:{approval_id}", self._timeout + 3600)` (keep for 1 hour after timeout for dashboard visibility).
     - Publish to `alerts:approval_request` channel: `json.dumps({"approval_id": approval_id, **context})`.
     - Create `asyncio.Future[str]` and store in `self._pending[approval_id]`.
     - **Cross-process resolution via Redis pub/sub:** Create an async task that subscribes to `alerts:approval_resolved` via Redis pub/sub (`self._redis.subscribe("alerts:approval_resolved")`). When a message arrives with matching `approval_id`, extract the `decision` and call `future.set_result(decision)` if the future is not already done. This ensures that resolutions from OTHER processes (dashboard, Slack bot) wake up the waiting future. Implementation:
       ```python
       async def _listen_for_resolution():
           pubsub = self._redis.pubsub()
           await pubsub.subscribe("alerts:approval_resolved")
           try:
               async for message in pubsub.listen():
                   if message["type"] != "message":
                       continue
                   data = json.loads(message["data"])
                   if data.get("approval_id") == approval_id and not future.done():
                       future.set_result(data["decision"])
                       break
           finally:
               await pubsub.unsubscribe("alerts:approval_resolved")
               await pubsub.aclose()
       listener_task = asyncio.create_task(_listen_for_resolution())
       ```
     - Use `asyncio.wait({future}, timeout=self._timeout)` to wait for resolution (the future can be set either by a direct in-process `resolve()` call OR by the pub/sub listener task from a cross-process resolution).
     - On timeout (future not done): cancel `listener_task`, call `await self._resolve_internal(approval_id, "timed_out")`, return `"timed_out"`.
     - On success: cancel `listener_task`, return the result string ("approved" or "rejected").
     - In a finally block: `self._pending.pop(approval_id, None)`, and cancel `listener_task` if still running.

     `async resolve(approval_id: str, decision: str) -> bool`:
     - Validate decision is "approved" or "rejected". Return False for invalid.
     - If `approval_id` in `self._pending` and the Future is not done: `future.set_result(decision)`.
     - Call `await self._resolve_internal(approval_id, decision)`.
     - Return True.

     `async _resolve_internal(approval_id: str, decision: str) -> None`:
     - Update Redis hash `approval:{approval_id}` with:
       - `status`: decision
       - `resolved_at`: `datetime.now(timezone.utc).isoformat()`
     - Publish to `alerts:approval_resolved`: `json.dumps({"approval_id": approval_id, "decision": decision})`.
     - Remove from `self._pending` if present.

     `async get_pending() -> list[dict]`:
     - Use SCAN to find all `approval:*` keys.
     - For each, HGETALL and filter where `status == "pending"`.
     - Return list of dicts with `approval_id` extracted from key name plus all hash fields.

     `async recover_expired() -> int`:
     - Called on startup to clean up stale approvals from a previous process.
     - Get all pending approvals via `get_pending()`.
     - For each, parse `timeout_at`. If `datetime.now(timezone.utc) > timeout_at`: call `_resolve_internal(id, "timed_out")`.
     - Return count of expired approvals auto-rejected.
     - Log each recovery action.

     Use structlog with component="approval_manager".

     - Add field: `approval_id: str` -- the approval request ID (empty if not applicable).
