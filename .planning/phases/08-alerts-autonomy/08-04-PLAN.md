  2. Create `src/trading/dashboard/routes/approvals.py`:
     - Create `router = APIRouter(prefix="/api", tags=["approvals"])`.

     - `GET /approvals/pending` -> `list[ApprovalResponse]`:
       - Get ApprovalManager from `request.app.state.approval_manager`.
       - If approval_manager is None, return empty list.
       - Call `await approval_manager.get_pending()`.
       - Map each dict to ApprovalResponse. Parse the context JSON string back into a dict.
       - Return list sorted by requested_at (oldest first).

     - `POST /approvals/{approval_id}/resolve` -> `ApprovalResolveResponse`:
       - Accept `ApprovalResolveRequest` body.
       - Get ApprovalManager from `request.app.state`.
       - Call `await approval_manager.resolve(approval_id, body.decision)`.
       - Return `ApprovalResolveResponse(success=result, approval_id=approval_id, decision=body.decision)`.
       - If approval_manager is None, raise HTTPException(503, "Approval manager not available").

     Use structlog with component="approvals_routes".

  3. Register the approvals router in `src/trading/dashboard/server.py`:
     - Import: `from trading.dashboard.routes.approvals import router as approvals_router`
     - Add `app.include_router(approvals_router)` alongside other routers.
     - In the lifespan startup, store approval_manager on app.state:
       - Create `ApprovalManager(redis=redis_client, timeout_seconds=settings.auto_execute.paper.approval_timeout_seconds if settings.trading.mode == "paper" else settings.auto_execute.live.approval_timeout_seconds)`.
       - Store as `app.state.approval_manager`.
       - Import `ApprovalManager` from `trading.alerts.approval` and `AutoExecuteConfig` from `trading.alerts.config`.

  4. Update `src/trading/dashboard/ws/bridge.py`:
     - Add `"alerts:approval_request"` and `"alerts:approval_resolved"` to the `CHANNELS` list.
     - Add mapping in `_map_channel`:
       - `alerts:approval_request` -> `approvals`
       - `alerts:approval_resolved` -> `approvals`
     Both map to the same `approvals` topic so the frontend gets all approval updates on one channel.
