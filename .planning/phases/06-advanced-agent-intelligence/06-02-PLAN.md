  Create `src/trading/agents/rolling.py` with:

  1. **RollingCandidate Pydantic model**:
     - `symbol: str`
     - `con_id: int`
     - `current_expiry: str` -- YYYYMMDD format
     - `days_to_expiry: int`
     - `position_size: float` -- positive = long, negative = short
     - `avg_cost: float`
     - `current_value: float | None = None` -- from portfolio()
     - `unrealized_pnl: float | None = None` -- from portfolio()
     - `right: str` -- "C" or "P"
     - `strike: float`
     - `rolling_reason: str` -- "approaching_expiry", "itm_risk", etc.

  2. **RollingDecision Pydantic model**:
     - `candidate: RollingCandidate`
     - `should_roll: bool`
     - `action: str` -- "roll", "close", "hold" (close = take loss, hold = let expire)
     - `target_expiry: str | None = None` -- new YYYYMMDD if rolling
     - `target_strike: float | None = None` -- new strike if adjusting
     - `reasoning: str`
     - `estimated_credit_debit: float | None = None`

  3. **ExpirationMonitor class**:
     - `__init__(self, ib: Any, config: RollingConfig)`: Store IB reference and config. Use `Any` type for IB to avoid import issues in tests (same pattern as other agents).

     - `async def scan_expiring_positions(self) -> list[RollingCandidate]`:
       - Call `self._ib.positions()` to get all account positions.
       - Filter to `secType == "OPT"` only.
       - For each option position, parse `lastTradeDateOrContractMonth` (YYYYMMDD format) into a date, compute DTE = (expiry_date - date.today()).days.
       - Keep positions where `DTE <= self._config.dte_threshold`.
       - Enrich with P&L data from `self._ib.portfolio()`: match by conId to get `unrealizedPNL` and `marketValue`.
       - Build and return `RollingCandidate` list sorted by DTE ascending (most urgent first).
       - If `self._ib.positions()` returns empty, log info and return empty list.
       - Catch exceptions from IB calls gracefully (log warning, return empty list).

     - `def evaluate_rolling(self, candidates: list[RollingCandidate]) -> list[RollingDecision]`:
       - For each candidate, decide: roll, close, or hold.
       - **Close (don't roll)** if: unrealized_pnl is known AND unrealized loss exceeds `config.max_loss_multiple * abs(avg_cost)` -- the trade thesis is invalidated, cut the loss.
       - **Hold** if: DTE > 0 AND position is profitable (unrealized_pnl > 0 or None) AND DTE > 1 -- let theta decay continue.
       - **Roll** otherwise: DTE is low, position not catastrophically losing. Compute target_expiry as today + config.preferred_roll_dte (format YYYYMMDD). Keep same strike by default; if `config.allow_strike_adjustment` and the position is ITM (would need current price to determine, so skip strike adjustment if current_value is None).
       - Build reasoning string for each decision explaining the logic.
       - Return list of RollingDecision.

     - `def build_roll_proposals(self, decisions: list[RollingDecision]) -> list[dict]`:
       - For each decision where `should_roll` is True or action is "close":
         - Build a close proposal dict with: symbol, right, strike, expiry (current), action=opposite of position (BUY to close short, SELL to close long), quantity=abs(position_size), strategy_type="roll_close".
         - If action is "roll" (not just close), also build an open proposal dict with: symbol, right, strike=target_strike or same strike, expiry=target_expiry, action=same as original position direction, quantity=abs(position_size), strategy_type="roll_open".
       - Return list of proposal dicts. These are serializable dicts (not Pydantic models) that can be stored in PipelineState `rolling_candidates` / `rolling_decisions`.

  Import from `datetime` (date, datetime). Import structlog. Use structlog logger bound to component="rolling".
  Do NOT import ib_async types -- use `Any` for the IB reference (prevents import errors in test environments without IB installed).
  Import RollingConfig from `trading.agents.config`.
  </action>
