  Create `src/trading/agents/regime.py` with:

  1. **MarketRegime enum** (str, Enum): BULL_QUIET, BULL_VOLATILE, BEAR_QUIET, BEAR_VOLATILE, SIDEWAYS, UNKNOWN. Use string values like "bull_quiet" for JSON serialization.

  2. **RegimeClassification Pydantic model**:
     - `regime: MarketRegime`
     - `confidence: float = Field(ge=0, le=1)` -- how confident the classification is
     - `trend_signal: str` -- "bullish", "bearish", or "neutral"
     - `volatility_signal: str` -- "high", "low", or "normal"
     - `indicators: dict` -- raw indicator values for audit trail (iv_rank_avg, momentum_avg, etc.)
     - `reasoning: str` -- human-readable explanation of why this regime was chosen
     - `previous_regime: MarketRegime | None = None` -- what regime was active before (for hysteresis tracking)

  3. **REGIME_STRATEGY_WEIGHTS** dict mapping MarketRegime -> dict[str, float]:
     - BULL_QUIET: covered_call=0.3, cash_secured_put=0.3, vertical_spread=0.2, iron_condor=0.2
     - BULL_VOLATILE: covered_call=0.3, vertical_spread=0.3, iron_condor=0.2, cash_secured_put=0.2
     - BEAR_QUIET: covered_call=0.4, vertical_spread=0.3, iron_condor=0.2, cash_secured_put=0.1
     - BEAR_VOLATILE: covered_call=0.5, vertical_spread=0.4, iron_condor=0.1, cash_secured_put=0.0
     - SIDEWAYS: iron_condor=0.4, covered_call=0.2, cash_secured_put=0.2, calendar_spread=0.2
     - UNKNOWN: covered_call=0.25, cash_secured_put=0.25, vertical_spread=0.25, iron_condor=0.25 (equal weights = no regime bias)

  4. **RegimeDetector class**:
     - `__init__(self, config: RegimeConfig)`: Store config. Initialize `_consecutive_count: int = 0` and `_pending_regime: MarketRegime | None = None` and `_current_regime: MarketRegime = MarketRegime.UNKNOWN` for hysteresis tracking.
     - `async def detect(self, iv_data: dict[str, IVData], price_data: dict[str, dict], vix_data: dict | None = None) -> RegimeClassification`:
       - Compute average IV rank across symbols that have non-None iv_rank (skip symbols with insufficient data). If no symbols have IV rank, return UNKNOWN with confidence 0.0.
       - Compute average price momentum from `price_data` dicts. Each dict should have a "last" key (current price) and optionally a "prev_close" or the detector can compute momentum from the set of prices. For simplicity, compute momentum as: gather all symbols' "last" and "prev_close" from Redis HGETALL data, compute per-symbol % change, average them. If no price data available, set trend to "neutral".
       - Classify volatility signal: iv_rank_avg > config.iv_rank_high_threshold = "high", iv_rank_avg < config.iv_rank_low_threshold = "low", else "normal". If VIX data available, also check vix_high/low thresholds and use the more extreme signal.
       - Classify trend signal: momentum_avg > config.momentum_bull_threshold = "bullish", momentum_avg < config.momentum_bear_threshold = "bearish", else "neutral".
       - Map (trend, volatility) to regime:
         - ("bullish", "low"/"normal") -> BULL_QUIET
         - ("bullish", "high") -> BULL_VOLATILE
         - ("bearish", "low"/"normal") -> BEAR_QUIET
         - ("bearish", "high") -> BEAR_VOLATILE
         - ("neutral", any) -> SIDEWAYS
       - Apply hysteresis: if computed regime differs from `_current_regime`, increment `_consecutive_count` if same as `_pending_regime`, else reset to 1 and set `_pending_regime`. Only switch `_current_regime` when `_consecutive_count >= config.hysteresis_count`. If computed regime equals `_current_regime`, reset counter.
       - Compute confidence: base 0.5 + 0.2 if iv_rank data available for >50% of symbols + 0.2 if price momentum data available + 0.1 if consistent with previous regime (hysteresis passed).
       - Build reasoning string explaining the classification.
       - Return RegimeClassification with all fields populated.

     - `def get_strategy_weights(self, regime: MarketRegime) -> dict[str, float]`: Return REGIME_STRATEGY_WEIGHTS[regime], defaulting to UNKNOWN weights if regime not found.

     - `@property current_regime(self) -> MarketRegime`: Return `_current_regime`.

  Import IVData from `trading.market_data.models`. Import RegimeConfig from `trading.agents.config`.

  Use structlog for logging (bind component="regime_detector"). Log regime detection results at info level, data insufficiency at warning level.
