**`evaluate_position_size(proposal: TradeProposal, limits: PositionLimits) -> RiskDecision | None`**

Pure function. Returns None if all checks pass, or a RiskDecision with the first violated rule.

Check order:
1. **Dollar limit**: Compare `proposal.max_loss` against `limits.max_dollars`. If exceeded, return violation with `POSITION_SIZE_DOLLARS` and details like `"Max loss $8,500.00 exceeds limit $5,000.00"`.
2. **Contract limit**: Sum `abs(leg.quantity)` for all legs where `leg.sec_type == "OPT"`. If total exceeds `limits.max_contracts`, return `POSITION_SIZE_CONTRACTS` violation with details.
3. **Portfolio percentage**: If `proposal.account_value > 0`, compute `pct = proposal.max_loss / proposal.account_value`. If `pct > limits.max_position_pct`, return `POSITION_SIZE_PERCENT` violation with details showing actual % vs limit %.

Follow the exact evaluator pattern from RESEARCH.md. Use `proposal.proposal_id` in the returned RiskDecision.
  </action>

from trading.risk.evaluators import evaluate_position_size
from trading.risk.models import TradeProposal, TradeLeg, GreeksImpact
from trading.risk.config import PositionLimits

limits = PositionLimits(max_dollars=5000, max_contracts=10, max_position_pct=0.05)
greeks = GreeksImpact(delta=0, gamma=0, theta=0, vega=0)

# Should pass
proposal = TradeProposal(legs=[TradeLeg(symbol='SPY', sec_type='OPT', action='BUY', quantity=2)], estimated_greeks=greeks, max_loss=3000, strategy_type='vertical_spread', account_value=100000)
result = evaluate_position_size(proposal, limits)
assert result is None, f'Expected pass, got {result}'

Add to `src/trading/risk/evaluators.py`:

**`is_naked_option(proposal: TradeProposal, existing_positions: list | None = None) -> bool`**

Detect if a proposal contains naked (uncovered) short options. Follow RESEARCH.md logic exactly:
- Find all short option legs (sec_type == "OPT" and action == "SELL")
- If no short options, return False
- For each short option leg, check if it is covered:
  - A covering long option exists in the SAME proposal (same symbol, sec_type OPT, action BUY) -- this covers spreads
  - For short calls: check if existing_positions (if provided) contain enough stock (quantity >= abs(short_leg.quantity) * 100 shares of the same underlying)
  - For short puts: check if existing_positions contain a long put on same underlying
  - If no cover found, return True (naked)
- Use `leg.right` field: "C" for call, "P" for put. A short call with right=="C", short put with right=="P".

**`evaluate_strategy_restrictions(proposal: TradeProposal, restrictions: StrategyRestrictions, existing_positions: list | None = None) -> RiskDecision | None`**

Check order:
1. **Allowlist check**: If `proposal.strategy_type` not in `restrictions.allowed_strategies`, return `STRATEGY_RESTRICTED` violation with details listing allowed strategies.
2. **Naked options check**: If `not restrictions.allow_naked_options` and `is_naked_option(proposal, existing_positions)`, return `NAKED_OPTION` violation with details.

Return None if all checks pass.
  </action>

from trading.risk.evaluators import evaluate_strategy_restrictions, is_naked_option
from trading.risk.models import TradeProposal, TradeLeg, GreeksImpact
from trading.risk.config import StrategyRestrictions

restrictions = StrategyRestrictions(allowed_strategies=['covered_call', 'vertical_spread'], allow_naked_options=False)
greeks = GreeksImpact(delta=0, gamma=0, theta=0, vega=0)

# Allowed strategy, no naked
spread = TradeProposal(
    legs=[
        TradeLeg(symbol='SPY', sec_type='OPT', action='BUY', quantity=1, right='P', strike=400.0),
        TradeLeg(symbol='SPY', sec_type='OPT', action='SELL', quantity=1, right='P', strike=410.0),
    ],
    estimated_greeks=greeks, max_loss=1000, strategy_type='vertical_spread', account_value=100000
)
assert evaluate_strategy_restrictions(spread, restrictions) is None

# Disallowed strategy
bad = TradeProposal(legs=[TradeLeg(symbol='SPY', sec_type='OPT', action='BUY', quantity=1)], estimated_greeks=greeks, max_loss=500, strategy_type='straddle', account_value=100000)
result = evaluate_strategy_restrictions(bad, restrictions)
assert result is not None and not result.approved
print('Strategy restrictions OK')
"
