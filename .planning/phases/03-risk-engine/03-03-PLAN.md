**`aggregate_portfolio_greeks(positions: list[dict]) -> PortfolioGreeks`**

Takes a list of position dicts, each with keys:
- `delta`, `gamma`, `theta`, `vega` (per-contract Greeks from Phase 2 data)
- `quantity` (signed: positive for long, negative for short)
- `multiplier` (usually 100 for options, 1 for stock)

Aggregation formula per RESEARCH.md:
```
portfolio_delta += position_delta * quantity * multiplier
portfolio_gamma += position_gamma * quantity * multiplier
portfolio_theta += position_theta * quantity * multiplier
portfolio_vega += position_vega * quantity * multiplier
```

Note: `quantity` is already signed (negative for short positions), so no separate sign flip needed. The caller provides signed quantities. Handle missing/None values by treating them as 0.0.

If `positions` is empty, return PortfolioGreeks with all zeros.
  </action>

Add to `src/trading/risk/greeks.py`:

**`evaluate_greeks_exposure(proposal: TradeProposal, limits: GreeksLimits, current_portfolio_greeks: PortfolioGreeks | None = None) -> RiskDecision | None`**

Pure function. Returns None if all checks pass, or a RiskDecision with the first violated Greek.

Logic:
1. Start with `current_portfolio_greeks` (or PortfolioGreeks() if None -- assumes empty portfolio).
2. Compute projected portfolio Greeks by adding the proposal's `estimated_greeks`:
   - `projected_delta = current.delta + proposal.estimated_greeks.delta`
   - Same for gamma, theta, vega
3. Check each Greek against its limit:
   - **Delta**: `abs(projected_delta) > limits.max_delta` -> DELTA_EXPOSURE violation
   - **Gamma**: `abs(projected_gamma) > limits.max_gamma` -> GAMMA_EXPOSURE violation
   - **Theta**: `projected_theta < limits.max_theta` -> THETA_EXPOSURE violation (theta limit is negative, represents max decay; more negative = worse)
   - **Vega**: `abs(projected_vega) > limits.max_vega` -> VEGA_EXPOSURE violation
4. Include both current and projected values in the details string for transparency: e.g., "Portfolio delta would be 650.0 (current: 400.0 + trade: 250.0), exceeds limit 500.0"

Short-circuit on first violation (check delta, then gamma, then theta, then vega).
  </action>
  <verify>
    python -c "
from trading.risk.greeks import evaluate_greeks_exposure, PortfolioGreeks
from trading.risk.models import TradeProposal, TradeLeg, GreeksImpact
from trading.risk.config import GreeksLimits

limits = GreeksLimits(max_delta=500, max_gamma=100, max_theta=-500, max_vega=1000)
current = PortfolioGreeks(delta=400, gamma=50, theta=-300, vega=500)

# Should fail: 400 + 200 = 600 > 500
proposal = TradeProposal(
    legs=[TradeLeg(symbol='SPY', sec_type='OPT', action='BUY', quantity=2)],
    estimated_greeks=GreeksImpact(delta=200, gamma=10, theta=-20, vega=50),
    max_loss=1000, strategy_type='vertical_spread', account_value=100000
)
result = evaluate_greeks_exposure(proposal, limits, current)
assert result is not None and not result.approved
assert 'delta' in result.details.lower()

# Should pass: within limits
proposal2 = TradeProposal(
    legs=[TradeLeg(symbol='SPY', sec_type='OPT', action='BUY', quantity=1)],
    estimated_greeks=GreeksImpact(delta=50, gamma=5, theta=-10, vega=20),
    max_loss=500, strategy_type='vertical_spread', account_value=100000
)
result2 = evaluate_greeks_exposure(proposal2, limits, current)
assert result2 is None
print('Greeks exposure evaluator OK')
"
