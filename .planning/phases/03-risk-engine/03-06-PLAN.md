**In TradingApp.__init__()** or startup():
1. Import RiskManager, CircuitBreaker, RiskRepository from trading.risk
2. Create `self.risk_repository = RiskRepository(session_factory=self.session_factory)`
3. Get the active risk limits profile: `risk_profile = self.settings.risk_limits.paper if self.settings.trading.mode == "paper" else self.settings.risk_limits.live`
4. Create `self.circuit_breaker = CircuitBreaker(redis=self.redis, repository=self.risk_repository, mode=self.settings.trading.mode, limits=risk_profile.loss)`
5. Create `self.risk_manager = RiskManager(limits=risk_profile, circuit_breaker=self.circuit_breaker, repository=self.risk_repository, ib=None, mode=self.settings.trading.mode)`
6. Note: ib is set to None initially. In `connect_ib()`, after IB connects, set `self.risk_manager.ib = self.connection_manager.ib` so margin checks become available.

**In connect_ib()** (after IB connection established):
- Set `self.risk_manager.ib = self.connection_manager.ib`
- Call `await self.circuit_breaker.load_from_db()` to restore halt state from Postgres (crash recovery)
- This is non-critical: wrap in try/except, log warning on failure (same pattern as IV bootstrap and earnings refresh)

**In shutdown()** -- no special cleanup needed for risk engine (it's stateless beyond Redis/Postgres which have their own cleanup).

Update `src/trading/risk/__init__.py` to ensure RiskManager, CircuitBreaker, RiskRepository, evaluate_with_failsafe, and all model types are exported.

- `test_position_size_passes_within_limits` -- all limits satisfied, returns None
- `test_position_size_rejects_dollar_limit` -- max_loss exceeds max_dollars
- `test_position_size_rejects_contract_limit` -- total OPT contracts exceed max_contracts
- `test_position_size_rejects_portfolio_pct` -- max_loss/account_value exceeds max_position_pct
- `test_position_size_zero_account_value_skips_pct` -- account_value=0 skips percentage check

**Greeks Exposure Tests:**
- `test_greeks_passes_within_limits` -- projected Greeks within all caps
- `test_greeks_rejects_delta_exposure` -- projected delta exceeds max_delta
- `test_greeks_rejects_theta_exposure` -- projected theta more negative than max_theta
- `test_greeks_none_portfolio_uses_zero` -- current_portfolio_greeks=None treated as zero
- `test_greeks_aggregation_with_short_positions` -- short positions have correct sign

**Strategy Restriction Tests:**
- `test_strategy_allowed_passes` -- strategy in allowlist, no naked options
- `test_strategy_disallowed_rejects` -- strategy not in allowlist
- `test_naked_option_detected_rejects` -- short option without covering long
- `test_spread_not_naked` -- short option with covering long in same proposal passes
- `test_naked_allowed_when_configured` -- allow_naked_options=True permits naked shorts

**Circuit Breaker Tests (use fakeredis):**
- `test_circuit_breaker_not_halted_passes` -- no halt, returns None
- `test_circuit_breaker_daily_halt_rejects` -- daily halt active, returns rejection
- `test_circuit_breaker_weekly_halt_rejects` -- weekly halt active, returns rejection
- `test_record_loss_triggers_daily_halt` -- loss exceeds daily limit, halt activates
- `test_record_loss_triggers_weekly_halt` -- loss exceeds weekly limit, halt activates
- `test_daily_reset_clears_daily_not_weekly` -- daily reset does not touch weekly state

**Margin Check Tests:**
- `test_parse_margin_str_valid` -- normal float string parses correctly
- `test_parse_margin_str_unset_double` -- UNSET_DOUBLE returns None
- `test_parse_margin_str_empty` -- empty string returns None
- `test_evaluate_margin_timeout_passes` -- timed_out=True returns None (pass-through)
- `test_evaluate_margin_negative_equity_rejects` -- equity_with_loan_after <= 0 rejects

**RiskManager Integration Tests (mock dependencies):**
- `test_check_trade_approved_all_pass` -- mock all evaluators to pass, verify approved=True
- `test_check_trade_short_circuits_on_first_violation` -- first evaluator fails, later ones not called
- `test_dry_run_does_not_accumulate` -- verify dry_run flag propagated, no side effects

**Fail-Safe Tests:**
- `test_failsafe_timeout_rejects` -- evaluate_with_failsafe returns RISK_MANAGER_UNAVAILABLE on timeout
- `test_failsafe_exception_rejects` -- evaluate_with_failsafe returns RISK_MANAGER_UNAVAILABLE on any exception
