Create `src/trading/risk/margin_check.py` following RESEARCH.md Pattern 5 exactly.

**`async check_margin(ib, contract, order, timeout: float = 5.0) -> MarginResult`**

- `ib` is an ib_async IB instance (type hint as `Any` or use `from ib_async import IB` if importable)
- `contract` is an ib_async Contract
- `order` is an ib_async Order
- Wrap `ib.whatIfOrderAsync(contract, order)` with `asyncio.wait_for(timeout=timeout)`
- On success, parse the OrderState fields:
  - `init_margin_after`: parse via `_parse_margin_str(order_state.initMarginAfter)`
  - `maint_margin_after`: parse via `_parse_margin_str(order_state.maintMarginAfter)`
  - `equity_with_loan_after`: parse via `_parse_margin_str(order_state.equityWithLoanAfter)`
  - `commission`: check if < 1e300 (IB UNSET_DOUBLE sentinel), else None (per Pitfall 2)
  - `warning_text`: `order_state.warningText or None`
  - Return MarginResult with timed_out=False
- On `asyncio.TimeoutError`: return MarginResult(timed_out=True) -- non-blocking per CONTEXT.md
- On any other exception: log warning, return MarginResult(timed_out=True) -- treat errors same as timeout

**`_parse_margin_str(value: str) -> float | None`** (private helper)
- Empty string or None -> return None
- Parse with float()
- If result > 1e300 (IB UNSET_DOUBLE) -> return None
- ValueError/TypeError -> return None

**`evaluate_margin(margin_result: MarginResult, account_value: float) -> RiskDecision | None`**
- If margin_result.timed_out: return None (timeout = pass-through per CONTEXT.md)
- If equity_with_loan_after is not None and equity_with_loan_after <= 0: return MARGIN_INSUFFICIENT rejection (trade would cause negative equity)
- If init_margin_after is not None and account_value > 0 and init_margin_after > account_value: return MARGIN_CHECK_REJECTED (margin exceeds account)
- Otherwise return None (margin check passed)

Use structlog with `bind(component="margin_check")`.

<task type="auto">
  <name>Task 2: RiskManager orchestrator with evaluator chain and fail-safe</name>
  <files>src/trading/risk/manager.py</files>
  <action>
Create `src/trading/risk/manager.py` with the RiskManager class -- the single entry point for all risk evaluation.

**`RiskManager`** -- initialized with:
- `limits`: RiskLimitsProfile (the active profile for current mode)
- `circuit_breaker`: CircuitBreaker
- `repository`: RiskRepository
- `ib` (optional): IB instance for margin checks (None if IB not connected)
- `mode`: str (paper/live)

**`async check_trade(self, proposal: TradeProposal, dry_run: bool = False, current_portfolio_greeks: PortfolioGreeks | None = None, existing_positions: list | None = None) -> RiskDecision`**

Evaluator chain order (short-circuit on first violation):

1. **Emergency halt check**: If `self.limits.emergency_halt` is True, return EMERGENCY_HALT rejection immediately.
2. **Auto-reset check**: Call `self.circuit_breaker.check_and_reset()` to handle market-open resets.
3. **Circuit breaker check**: Call `self.circuit_breaker.check()`. If returns a RiskDecision, that's a rejection -- return it.
4. **Position sizing**: Call `evaluate_position_size(proposal, self.limits.position)`. If returns a RiskDecision, return it.
5. **Greeks exposure**: Call `evaluate_greeks_exposure(proposal, self.limits.greeks, current_portfolio_greeks)`. If returns a RiskDecision, return it.
6. **Strategy restrictions**: Call `evaluate_strategy_restrictions(proposal, self.limits.strategy, existing_positions)`. If returns a RiskDecision, return it.
7. **Margin check** (only if self.ib is not None and proposal has contract/order data on at least one leg):
   - For each leg with contract and order set, call `check_margin(self.ib, leg.contract, leg.order, self.limits.margin_check_timeout)`
   - Call `evaluate_margin(margin_result, proposal.account_value)`
   - If rejected, return with margin_result attached
   - Store the margin_result on the decision for audit

8. If all pass: return RiskDecision(approved=True, proposal_id=proposal.proposal_id, dry_run=dry_run)

**Important**: Set `dry_run` flag on every returned RiskDecision. Set `proposal_id` on every returned RiskDecision.

**After evaluation (not in dry_run mode)**: Call `self.repository.save_decision(decision, self.mode)` to persist the audit record. In dry_run mode, still persist but with dry_run=True flag.

**`async evaluate_with_failsafe(risk_manager: RiskManager, proposal: TradeProposal, timeout: float = 10.0, **kwargs) -> RiskDecision`** (module-level async function, NOT a method)

Per RESEARCH.md Pattern 3:
- Wrap `risk_manager.check_trade(proposal, **kwargs)` with `asyncio.wait_for(timeout=timeout)`
- On ANY exception (TimeoutError, RuntimeError, ConnectionError, etc.): return RiskDecision(approved=False, violated_rule=RISK_MANAGER_UNAVAILABLE, details="Risk manager evaluation failed or timed out", proposal_id=proposal.proposal_id)
- This is the function that Phase 4's order execution will call. It guarantees a trade is NEVER submitted without explicit approval.

Update `src/trading/risk/__init__.py` to export RiskManager and evaluate_with_failsafe.

Use structlog with `bind(component="risk_manager")`. Log at INFO level for approved trades, WARNING for rejected trades.
